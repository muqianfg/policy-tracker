# 新闻联播 → 行业影响 → 可验证预测

一个每天自动运行的**公开政策分析 + 预测跟踪**系统。

它做的事情很简单：每天读《新闻联播》，把政策术语翻译成人话，推演它对行业和个人的影响，然后**写下一个可被证伪的判断**，并在之后的每一天回来核对 —— 对了、错了、还是没有下文，全部留痕。

---

## 为什么要"写下可被证伪的判断"

绝大多数新闻解读的问题不是不专业，而是**不可检验**：
- "XX 行业有前景" —— 什么时候？什么信号？错了怎么算？
- "国家支持消费" —— 说了等于没说。

这个项目要求每条判断必须包含：**明确结论 + 依据（可追溯的原文/数据）+ 验证方式（盯什么指标）+ 时间窗 + 置信度**。
然后到时间回来对账。**判断错了也保留原答案，只能追加修正说明。**

> 一个敢公开对账的预测记录，比一百条永远正确的评论更有价值。

## 一条判断长什么样

```
【答案 ID】T-20261009-01
【问题】《关于发展新质生产力的意见》印发后，最先出现可核查落地的
        会是"新增支持"还是"收紧整顿"？
【我的答案】收紧整顿先到。未来 6 个月内会先出现以"清理借新质生产力
        名义套取政策/补贴、盲目投资项目"为名的核查与叫停案例……
【依据】文件把"追责"和"严禁滥用"写在了与"支持"同等显著的位置
【验证方式】省级/地市级项目复核、暂停、清理通报；补贴追回与问责案例
【时间窗】6 个月
【趋势判断】长期向上，短期"先规范、后铺开"
【置信度】中
```

**第二天的进展**：国家发改委就《意见》答记者问，明确"严禁借发展新质生产力之名搞恶性招商引资、盲目'跟风'上项目、乱'烧钱'"，并点名两类被纠偏的做法。
→ 证据支持，置信度由「中」上调为「中高」。**但按自定标准只上调一档** —— 因为这是执行信号，不是订单证据。

## 附带一个 AI Skill

仓库里带了一份 **DSH / Claude Code 风格的 Skill**：`.dsh/skills/news-policy-tracking/SKILL.md`。

它把这套系统的**五条铁律、文件地图、每日流程、更新信号档案的步骤、以及踩过的坑**固化成一个可被 AI 直接加载的指令文件 —— 任何支持 skill 的 agent 读它就能接手维护，不需要从头解释。

> 为什么放在这里：这套系统的规则已经迭代了七八轮（说人话、只追加带日期、个人影响同步更新、置信度一次最多升一档……），靠人记会漏。**规则写进模板，模板写进 skill，才不会重犯。**

### 一条信号文件里有什么

| 区块 | 内容 |
| --- | --- |
| 头部表格 | ID、状态、趋势判断、时间窗、置信度、立档日、最后更新、证据条数 |
| 一、问题 | 一句话，必须**可被证伪** |
| 二、我的答案 | 明确判断：会发生什么、在哪个行业、什么节奏 |
| 三、验证方式 | 盯什么指标、出现什么算支持、什么算推翻 |
| 四、证据时间线 | **只追加**。每条形如：日期 · 来源 · 事实 · 我的解读 · 对判断的影响（维持/增强/减弱/推翻） |
| 五、复盘 | 时间窗到期或被验证/推翻时填写 |
| 六、修正记录 | 置信度或判断变更的原因，保留原始判断 |
| 七、对我的个人影响与行动项 | 这条信号对我意味着什么，以及**带具体日期的行动清单**（计划日期 / 预计耗时 / 状态） |

> 设计要点：**个人影响不写在日报里，而是挂在对应的信号上** —— 因为"这件事对我意味着什么"本来就属于那条信号，挂在信号下才能带日期追踪执行。日报因此更干净，只保留条目单、三件大事、行业影响、今日答案与视频候选。

## 方法论核心

**四层影响推演**（每条新闻都要走完）：

```
第 1 层 事实层：发生了什么（量、时间、主体）
第 2 层 传导层：钱和政策沿着哪条链子往下走（谁付钱 → 谁接单 → 谁受益/受损）
第 3 层 行业层：直接受益 / 间接受益 / 被挤压
第 4 层 个人层：对"我"的时间、钱、技能、资源的具体影响 → 落到"下周可做的三件事"
```

**什么才算"新证据"**（防止自己骗自己）：

| 算 | 不算 |
| --- | --- |
| 新的资金、订单、招标、价格 | 又一次会议报道 |
| 政策文件、产能变化 | 领导表态、例行宣传 |
| 企业实际动作 | 被更高层文件"点名确认方向"（可在日志注明"政策确认，非订单证据"，但**不得据此上调置信度**） |

**只追加，不改写**：历史判断永不修改。要修正就另起一条，保留原答案与错误。

## 数据来源

- 《新闻联播》条目单：取自央视官方页面（`tv.cctv.com`），四级降级：页面 meta → 页面正文"本期节目主要内容" → 栏目页 → 兜底文件

- 统计数据：税务总局增值税发票数据、国新办发布会、统计局
