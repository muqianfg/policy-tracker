解读方法论（Playbook）

这份文件定义"怎么把新闻联播读成机会"，每晚执行时按此标准产出。

一、四条铁律

  1. 不停在"读新闻"。复述条目 = 没做工作。每条都必须回答"所以呢"。
  2. 必须写出答案。没有判断的分析是无效分析。答案是可证伪的一句话，不是感想。
  3. 必须持续跟踪。答案写下后进入跟踪池，每天回看，直到验证或推翻。
  4. 必须说人话（第四条铁律，2026-10-14 新增）。内容是给普通人看的。任何专业词第一次出现，必须先用一句话解释它是什么、与普通人有什么关系，之后才能用简称。

三档解释规则（2026-10-16 确立）

同一个专业词在三个场景里的解释规则不同，因为读者的处境不同：

场景规则为什么
日报当天第一次出现就解释日报是独立的一天，读者可能只看这一天
信号档案整个档案第一次出现解释，之后不再解释档案是累积的，从头读到尾只遇到一次
口播稿讲到哪就解释到哪，不管之前解释过几次视频是线性的，观众不能往前翻；每期都是新观众

一句话：文字内容按「第一次」算，视频内容按「每一次」算。

视频里解释的时机：讲到那个词的时候顺手解释，不要提前堆在开头 —— 那样观众记不住，也破坏节奏。

第四条铁律的执行标准

❌ 错误：「PPI 连涨七个月，而 CPI 只有 0.9%」 ✅ 正确：「工厂的出厂价格（专业叫法是 PPI）已经连涨七个月……而老百姓买东西的价格（CPI）只涨了 0.9%」

  • 判断标准：把这句话念给一个不看财经新闻的人听，他能听懂吗？听不懂就是没解释。
  • 常见格式：先人话，括号补专业词 —— 「老百姓买东西的价格（CPI）」「整个社会借了多少钱（社融）」
  • 术语表：模板/术语对照表.md 收录了常用词的人话解释，写作时对照使用；出现表里没有的新词，必须补进去。
  • 这条规则同时适用于：日报正文、视频脚本、README 公开摘要、以及任何对外输出。

二、术语翻译规则

新闻联播的词汇是政策工具名，每个词背后都有资金流向和考核指标。翻译时问四个问题：

问题为什么问
钱从哪来、到哪去、多大规模？财政/货币表述决定谁是买方
谁被考核、什么时候交卷？"工程/行动/试点"通常带时间表，时间是订单节奏
是新提法还是例行表述？新提法 = 政策拐点；例行表述 = 噪音
排在第几条？排序即优先级，头条和联播快讯的信息量差一个量级

常见术语速查：

  • 新质生产力 → 政策资源向硬科技、先进制造倾斜；传统要素行业相对失血
  • 全国统一大市场 → 地方保护被拆，跨区域经营的公司受益，靠地方壁垒活着的公司受损
  • 专项债 / 特别国债 / 超长期国债 → 财政加杠杆，基建、设备更新、以工代赈类订单前置
  • 以旧换新 / 设备更新 → 直接补贴终端购买，家电、汽车、工业设备短期销量弹性
  • 扩内需 / 消费大市场 → 关注消费券、服务业准入、免签、消费税相关动作
  • 反内卷 / 防止恶性竞争 → 行业价格战被行政干预，利好龙头、利空靠低价抢单的小厂
  • 耐心资本 / 长期资金入市 → 险资、社保、汇金类资金增量，对应大盘蓝筹与红利资产
  • 一带一路 / 中欧班列 / 海外仓 → 出口结构变化，跨境电商与工程承包
  • 人工智能+ / 具身智能 → 算力、机器人本体、场景数据三条链
  • 民生保障类（医保、养老、生育、教育） → 财政刚性支出，对应服务供给缺口

三、影响推演框架

对每个入选条目走一遍四层：

第 1 层 事实层：发生了什么（量、时间、主体）
第 2 层 传导层：钱和政策沿着哪条链子往下走（谁付钱 → 谁接单 → 谁受益/受损）
第 3 层 行业层：直接受益行业 / 间接受益行业 / 被挤压行业
第 4 层 个人层：对"我"的时间、钱、技能、所在地、可触达资源的具体影响

第 4 层必须落到可执行动作："下周可以做的三件事"这种粒度。

四、答案写法（最重要）

【答案 ID】T-YYYYMMDD-NN
【问题】可被证伪的一句话
【我的答案】明确判断
【依据】今天的第 N 条新闻 + 什么信息
【验证方式】盯哪个指标/事件
【时间窗】3 / 6 / 12 个月
【趋势判断】向上/向下/震荡/尚不明朗
【置信度】高/中/低 + 缺什么信息

好答案 vs 坏答案：

坏答案好答案
康复护理行业有前景未来 12 个月康复护理床位扩张会带动康复器械招标放量，盯各省卫健委采购公告，季度招标额同比转正即为验证
关注人工智能具身智能的订单会先在汽车/3C 工厂出现而非家庭场景，6 个月内看工业机器人订单结构里"带视觉+大模型"占比是否提升
国家支持消费消费刺激会从补贴商品转向补贴服务（文旅/养老/家政），3 个月内看服务消费券在地方的落地规模

四点六、影响判断的三分法（2026-10-22 新增，硬要求）

问题：以前的"机会窗口"写成了"投资者可以关注""创业者有空间"——这是套话，任何人都能说，读者拿不到任何可行动的信息。

三分法：每一条影响判断必须同时写清三件事

分法要回答什么反面示例（禁止）正面示例
一、创业风口谁在花钱、买什么、谁能接、单笔多大、什么时候"创业者有切入空间""省文物局招标三维扫描，单个县 30~80 万，需要测绘乙级资质，窗口在每年 3~6 月"
二、投资影响哪些环节被实质影响、举例主体、传导路径、财报验证点"投资者可关注相关板块""上游电池（业务定位：动力电池），因为重卡换电需要更大容量，看装机量增速与毛利"
三、个人生活身边能看到什么、价格与流程怎么变、岗位怎么变"对个人有影响""小区充电桩变多、夜里电价更低、修电动车的人比修燃油车的更吃香"

判断标准（唯一标准）：读者能不能凭这句话去查、去买、去接单、去观察？ 不能就是套话。

投资影响的合规边界

这条线必须守住：

✅ 可以写❌ 不能写
受影响主体的业务定位（"做动力电池的"）股票代码、买入价、目标价
传导路径（为什么受影响）"会涨""值得买""建仓"
财报验证点（看哪个指标能证实）收益承诺、时间点预测
相关大宗/期货品种与联动逻辑具体合约与点位

理由：描述"哪些主体的业务会被实质影响"是产业分析；说"买什么会赚钱"是投资建议。前者可写，后者不能写。每条都要标「非推荐」。

四点七、跨链传导（2026-10-25 新增，因方法缺陷而加）

问题（真实案例）：2026-10-25 写造船信号时，三分法只写到"船厂、船板、船舶电气、铜、热卷"就停了。 用户问："造船和电商的关系呢？" —— 一查就发现这条链一直通到跨境电商头层运费（全球集装箱船手持订单超 1,400 万 TEU = 现有船队 42%，2027 年运力增速可能 9%）。 三分法从没逼自己走这一跳，这是结构性缺陷，不是记性差。

三分法的盲区

三分法问的视角盲区
上中下游 + 期货品种产业链内部这个变化还改变了哪个行业的关键参数？

第四问：跨链传导

每条信号写完三分法后，必须再问一次：

"这个变化，还改变了哪个不在本产业链里的行业的关键成本、关键能力或关键门槛？"

三种典型模式（照着套）：

模式含义例子
成本阀门这个行业产出的价格，是另一个行业的输入成本造船 → 运力 → 运价 → 跨境电商头层成本
能力瓶颈这个行业的产品，是另一个行业能不能扩产的前提芯片 → 算力 → AI 应用；船台 → 运力
门槛变化这个行业的规则/标准，抬高或降低了另一个行业的准入团体标准 → 验收口径 → 采购门槛

硬要求

  1. 每个信号文件头部必须有 关联信号 字段，列出受影响的其他信号 ID（没有就写"无"，但要说明为什么真的没有）
  2. 每条证据时间线的更新，要同步检查 关联信号 字段是否需要增补
  3. 跨链传导写不出来，说明这条信号只值一条新闻，不值一个档案

四点五、个人影响的时间纪律（2026-10-15 新增）

个人影响不是一次性写的。每次信号有更新时，同步更新个人影响，且必须追加、带日期。

三条硬规则

  1. 只追加，不覆盖。写新内容前先加日期小标题 ### YYYY-MM-DD，历史内容永不删改。
  2. 行动项必须带两个日期：记录日（加它的那天）+ 计划日期（打算做的那天）。
  3. 改状态不删行：完成/放弃/顺延都在原行的待办文字后追加说明，例如「顺延至 2026-10-18，原因：当天有其它到期项，合并执行更有效率」。

为什么要这么严

"我对同一件事的判断在三个月里变了"本身就是最有价值的记录。 如果每次更新都覆盖，你就永远看不到自己的认知是怎么变化的 —— 而这恰恰是校准复盘（每 3 个月一次）的原料。

与证据时间线的对称性

四、证据时间线七、个人影响与行动项
记录什么世界发生了什么我因此怎么想、要做什么
更新节奏有新证据时信号更新时同步更新
纪律只追加 + 带日期只追加 + 带日期 + 行动项双日期
永不删改✅✅

两条线合起来，才构成一条完整的判断记录：世界怎么变、我怎么变。

五、跟踪纪律

  1. 每天回看最近 30 天的未结答案，逐条判断：有证据支持 / 有证据反对 / 无新进展。
  2. 无新进展也要写一行，因为"迟迟没有下文"本身是趋势信号（政策落地能力的一种体现）。
  3. 只允许追加，不允许改写历史判断。修正要新开一条"修正说明"，并保留原答案。
  4. 置信度会随时间衰减：超过时间窗仍未验证的答案，标记为「超期未验证」并归因（是判断错、还是传导慢、还是被新政策覆盖）。
  5. 每满 3 个月做一次校准复盘，统计命中率，并写下自己的系统性偏差（例如总是高估政策落地速度）。

六、常见陷阱

  • 把口径当信号：会议报道、总结性表述、年度例行内容通常不含新增信息。
  • 把排序当全部：快讯里的短条目偶尔藏着真金（例如某项技术突破、某个标准落户），要单独看。
  • 忽略国际条目的传导：地缘、油价、航运、关税会通过成本和大宗价格直接影响个人投资。
  • 过度自信：政策到产业落地通常要 2~4 个季度，别把"表态"当成"已经发生"。
  • 只找利好：被挤压的行业往往藏着更确定的信号（做空、规避、退出时机）。

⚠ 历史教训（2026-11-01 从总控会话迁移过来，这是在实践中踩过的坑，必须遵守）

一、口径陷阱（最容易犯的错）

看到任何数字，先问一句「这个数字的口径是什么」：

官方常给的说法真实含义别搞错成
「涉及项目总投资 11.6 万亿」项目未来几年要花的钱今年要花的钱
「装机容量 25.18 亿千瓦」设备的名义能力实际发电量（只有 41.8%）
「设计效率 91.3%」发电机组效率全流程往返效率（只有 50~60%）
「五年年均增长 31.9%」过去五年的复合增速今年的增速
「带动销售额 2 万亿」可能是存款搬家不是新增消费消费真的变强了

规则：宁可写「口径不明，无法判断」，也不要直接采信。

二、时间尺度陷阱

不同新闻的时间尺度差很多，混用会得出完全错误的结论：

类型才能变成实际影响的时间
算力网/储能项目建设1~3 年
政策文件 → 订单6~12 个月
找矿/勘查成果 → 实际产量5~10 年

已犯过的错：「找矿突破」→ 说「铜供给要增加、铜价要跌」。实际上勘查成果对 6 个月内的铜价影响为零。

三、总量 vs 结构

很多数据是「总量温和、结构剧变」，只报总量会严重误导：

  • 物流：总量只 +4.9%，但工业品 +5.3%（贡献 78%）、消费物流只 +2.9%
  • 外贸：五年年均只 +4.5%，但新三样 +31.9%、民营占比 53.8% 到 64.1%
  • 贷款：各项贷款 +4.8%，但科技型中小 +20.1%、房地产 −5.2%

规则：凡是总量数据，必须同时报结构与增速差。

四、中国官方通稿的规律

通稿越短，实质越少。

  • 德国总统访华：新华社正文只有一句「举行会谈」，未披露任何合作内容 → 说明没有实质成果
  • 如果真签了协议，通稿一定会写细节、金额、项目清单

五、经济新闻稀少时，如实说比硬凑强

2026-10-30 那一天，16 条主条目里 15 条是党建或外交，只有 1 条经济数据。

正确做法：在日报开头明写「今天没有经济新闻，这本身就是信息」，然后深挖那一条。 错误做法：把党建新闻硬解读成经济信号，或凑三条凑不满的三件事。

已记录的事实：重大全会后 1~2 周，新闻必然以「学习贯彻」为主 —— 这是会议周期的正常现象，不是政策转向。

六、一条已确认的跨来源结论（可直接引用）

「消费偏弱」已经被四个独立来源确认，可以当作既定事实使用：

来源数据
央行 2026Q3住户贷款 −2.0%、消费贷 −2.8%
统计局文化企业文化批发零售 −0.1%
商务部以旧换新 2 万亿，但钱来自存款搬家不是信贷
物流联合会单位与居民物品物流只 +2.9%（工业品 +5.3%）

七、一条已确认的跨系统验证

新闻 + 期货互相验证成功过一次（2026-10-28）：

  • 新闻端：金杯电工总经理说「铜价从每吨 7 万余元涨到近 10 万元」
  • 期货端：我们实测铜月差仅 +0.6%（弱 Backwardation）→ 现货不紧，下游在抵制高价
  • 结论：下游在抵制高价，但没有崩

这个方法论可以复用：新闻里的企业原话 + 期货里的月差数据，互相印证。
