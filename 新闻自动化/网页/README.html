新闻联播 → 行业影响 → 可验证预测

一个每天自动运行的公开政策分析 + 预测跟踪系统。

它做的事情很简单：每天读《新闻联播》，把政策术语翻译成人话，推演它对行业和个人的影响，然后写下一个可被证伪的判断，并在之后的每一天回来核对 —— 对了、错了、还是没有下文，全部留痕。

为什么要"写下可被证伪的判断"

绝大多数新闻解读的问题不是不专业，而是不可检验：

  • "XX 行业有前景" —— 什么时候？什么信号？错了怎么算？
  • "国家支持消费" —— 说了等于没说。

这个项目要求每条判断必须包含：明确结论 + 依据（可追溯的原文/数据）+ 验证方式（盯什么指标）+ 时间窗 + 置信度。 然后到时间回来对账。判断错了也保留原答案，只能追加修正说明。

一个敢公开对账的预测记录，比一百条永远正确的评论更有价值。

一条信号文件里有什么

区块内容
头部表格ID、状态、趋势判断、时间窗、置信度、立档日、最后更新、证据条数
一、问题一句话，必须可被证伪
二、我的答案明确判断：会发生什么、在哪个行业、什么节奏
三、验证方式盯什么指标、出现什么算支持、什么算推翻
四、证据时间线只追加。每条形如：日期 · 来源 · 事实 · 我的解读 · 对判断的影响（维持/增强/减弱/推翻）
五、复盘时间窗到期或被验证/推翻时填写
六、修正记录置信度或判断变更的原因，保留原始判断
七、对我的个人影响与行动项这条信号对我意味着什么，以及带具体日期的行动清单（计划日期 / 预计耗时 / 状态）

设计要点：个人影响不写在日报里，而是挂在对应的信号上 —— 因为"这件事对我意味着什么"本来就属于那条信号，挂在信号下才能带日期追踪执行。日报因此更干净，只保留条目单、三件大事、行业影响、今日答案与视频候选。

方法论核心

四层影响推演（每条新闻都要走完）：

第 1 层 事实层：发生了什么（量、时间、主体）
第 2 层 传导层：钱和政策沿着哪条链子往下走（谁付钱 → 谁接单 → 谁受益/受损）
第 3 层 行业层：直接受益 / 间接受益 / 被挤压
第 4 层 个人层：对"我"的时间、钱、技能、资源的具体影响 → 落到"下周可做的三件事"

什么才算"新证据"（防止自己骗自己）：

算不算
新的资金、订单、招标、价格又一次会议报道
政策文件、产能变化领导表态、例行宣传
企业实际动作被更高层文件"点名确认方向"（可在日志注明"政策确认，非订单证据"，但不得据此上调置信度）

只追加，不改写：历史判断永不修改。要修正就另起一条，保留原答案与错误。
