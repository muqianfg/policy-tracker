## 一、两套配色

| | **A · 米白 + 宋体 + 酒红** | **B · 暖米 + 橙红** |
| --- | --- | --- |
| 主题 ID | `editorial-serif` | `magazine-bold` |
| 底色 | 米白（暖调的浅灰白） | 暖米（偏黄的米色） |
| 主色 | 酒红 | 橙红 |
| 标题字体 | 衬线（宋体类） | 无衬线粗体 |
| 正文 | 宋体，字重偏轻 | 无衬线，字重中等 |
| 气质 | 杂志深度报道 · 有分量 · 慢思考 | 时尚杂志 · 有冲击力 · 快节奏 |
| 适合内容 | 政策解读、数据复盘、长逻辑链 | 热点解读、单条新闻、短视频 |
| 风险 | 衬线字小屏略细 | 暖黄底在某些屏偏黄 |

**对比图**：[对比-editorial-serif vs magazine-bold.png](对比图-两套配色.png)

## 二、怎么用

在视频脚本 JSON 里加一行：

```json
"theme": "editorial-serif"   // 或 "magazine-bold"
```

不写这一行时，**默认用 `editorial-serif`**。

如果写了不在名单里的主题，脚本会打印警告并回退到默认值 —— 避免再次出现"主题没生效却以为生效了"。

## 三、换主题的实际操作

```
cd D:\自动化任务
node 新闻自动化\视频\工具\make-video.mjs 新闻自动化\视频\脚本\<名字>__editorial-serif.json
```

成片输出到 `新闻自动化\视频\成片\`，文件名带主题名，两版可以并存对比。

## 四、一条必须记住的教训

**2026-10-26 犯过一次错**：主题 CSS 的 `<link>` 路径少算一级，导致 CSS 加载失败，
页面回退到兜底色（深色 + 金色）。而**两条视频的命令都返回了退出码 0**，
我没有抽帧检查就报告"两版主题已生成"，实际两版一模一样。

**现在的规矩**：

1. 主题类改动，**出片前必须先抽一帧确认颜色**
> 抽帧命令：`ffmpeg -ss 24 -i 成片.mp4 -frames:v 1 check.png`
2. **"命令成功"不等于"结果正确"**，视觉类改动尤其不能只看日志
3. 主题白名单机制已加，写错主题名会自动回退并警告
