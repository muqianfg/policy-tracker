【每日任务 · 新闻联播简报 + 趋势跟踪】请完整执行以下流程，不要中途停下来问我问题。

工作目录：D:\自动化任务

第 1 步 · 抓取
在 D:\自动化任务 下执行：node scripts\new-daily.mjs
它会生成当天日报骨架 daily\YYYY-MM-DD.md（YYYY-MM-DD = 当天日期，按 Asia/Shanghai），并把当天 19:00《新闻联播》的完整条目单打印出来。
数据源异常的处理（重要，务必照做）：
- 央视官方页面有时当晚尚未填充条目单（表现为"主条目 0 条"或脚本报"description 为空/过短"）。脚本此时会显式告警。
- 遇到告警不要慌，也不要编造条目：改用 web_search 搜索"新闻联播 {当天日期} 主要内容"，从媒体整理的条目单（如钛媒体、同花顺、华夏时报等）取得完整条目，据此分析。
- 必须在日报末尾的「附：今日条目单来源说明」中写明：官方源是否可用、实际用了哪几个兜底来源、以及是否逐条核查过政策原文。
- 条目单只是线索：凡是当天最重要的政策/文件，一律用 web_fetch 打开原文（gov.cn、部委网站、财政部等）核对金额、时间表、指标，再写分析。不要只依据媒体摘要下判断。

第 2 步 · 解读（先读规则）
先读 templates\analysis-playbook.md 与 templates\daily-template.md，按其中的标准产出。
身份视角固定为：自由职业者 / 投资者 / 创业者，正在寻找机会，不预设行业；"目标行业"就是当天新闻所牵涉的行业本身。
铁律：不要停在复述新闻上。每条都必须回答"所以呢"。

第 3 步 · 分析并写入 daily\YYYY-MM-DD.md
- 从条目单里挑 3 件真正有信息量的（有钱、有政策抓手、有时间表、有新提法），每件走完四层：术语翻译 → 真信号（谁付钱、谁接单、多大规模、什么时间表）→ 行业传导（直接受益/间接受益/被挤压）→ 机会窗口（自由职业/投资/创业各一条）+ 反面（可能是噪音的理由）。
- 行业影响表：方向、钱怎么流、时间节奏、关注信号。
- 个人影响：时间/钱/技能/资源，并给出"下周可以做的三件事"。
- 顶级文件（党中央/国务院印发）要特别区分"支持什么"和"禁止什么"——约束条款往往比支持条款更有信息量。
- 最后填写日报的「六、视频候选」一节：按 硬指标 / 有钱 / 新提法 / 推翻直觉 / 传导链清晰 五个维度打分（各 1 星），已跟踪信号出现新证据的直接入选。每天只标 0~2 条；没有值得拍的，明确写"今日无候选"，不要硬凑。这一节是为每周视频选材积累材料，成本很低但必须做。

第 4 步 · 写下答案（最重要的步骤，不可跳过）
当天必须写出 1~3 条**可被证伪的判断**，不是新闻摘要，格式：
【答案 ID】T-YYYYMMDD-NN ／【问题】／【我的答案】／【依据】／【验证方式】／【时间窗】／【趋势判断】／【置信度】
证据不足时如实写"尚不明朗"并说明缺什么信息；绝不把噪音包装成机会。

第 5 步 · 更新跟踪档案（只追加，不改写历史）
编辑 tracking\趋势追踪.md，必须完成下面各项，缺一不可：
(a) 新答案追加进「答案登记表」（表格一行：答案 ID、立档日、问题、我的答案、趋势判断、时间窗、置信度、状态=待验证）。
(b) 在「趋势进展日志」末尾追加当天的小节，标题格式为三个井号加空格加日期（### YYYY-MM-DD），位置在该节已有内容的最后一天之后、下一节标题之前。
   这是最容易出错的一步：写完必须重新读取文件确认这一节真的存在、内容完整、位置正确；不要相信写入操作的返回值（历史教训：写入报成功但内容并不在文件里）。
(c) 小节内容顺序：回看最近 30 天内所有未结答案，**逐条**写"新证据 / 方向是否变化 / 下一步看什么"。无新进展也要写一行"无新进展"。
(d) 判断"新证据"的标准：出现新的资金、订单、招标、价格、政策文件、产能或企业动作。又一次会议报道、表态、或被更高层文件"点名确认方向"，都**不算**新证据，不得据此上调置信度（可在日志里注明"政策确认，非订单证据"）。
(e) 只追加，不重写整份文件，不修改历史判断；需要修正时另起一条修正说明并保留原答案。
(f) 把新增答案的完整结构化内容（问题/我的答案/依据/验证方式/时间窗/趋势判断/置信度）追加进「完整答案存档」区，避免长答案在表格里被截断。
(g) 若某条答案已满 3 个月，做一次校准复盘写进「校准复盘」区。

第 6 步 · 交付
把当天简报正文（三件事 + 行业影响 + 个人影响 + 今日答案）直接输出在对话里给我看，不要只说"已写入文件"。
结尾必须说明：今天新增了几条答案、有没有历史答案被新证据支持或推翻（被"政策点名"不算支持）、今天有几条视频候选、下一次要盯什么信号。
如果今天的数据源出现了异常（官方条目单缺失等），也要在结尾如实说明。
