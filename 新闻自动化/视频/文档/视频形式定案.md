## 一、已经定下来的（五条）

### 1. 频率与时长（2026-10-15 更新）

| 项 | 定案 | 口播字数（300 字/分钟） |
| --- | --- | --- |
| **日更短视频** | **约 3 分钟** | 约 **900 字** |
| **周更长视频** | **约 20 分钟** | 约 **6000 字** |
| **每月对账专期** | 待定 | — |

### 1c. 3 分钟短视频的结构

| 段 | 时长 | 内容 |
| --- | --- | --- |
| 钩子 | 0:00-0:15 | 一条判断 + 今天它动了（制造"跟我有关"） |
| 背景 | 0:15-0:45 | 这条判断是什么、什么时候写的、为什么普通人该关心 |
| 新证据 | 0:45-1:30 | 谁、做了什么、来源、**把专业词翻译成人话** |
| 解读 | 1:30-2:15 | 意味着什么 + **诚实说明验证了几成** + 置信度有没有调整及为什么 |
| 下一步 | 2:15-2:45 | 我接下来盯什么 |
| 结尾 | 2:45-3:00 | 时间窗 + 回来对账 + 免责声明 |

> **这次改动的连带影响（重要）**：
> - 3 分钟 ≠ 把 105 秒的稿子拉长。3 分钟要求**把一件事讲透**：为什么跟我有关 → 它是什么 → 发生了什么 → 意味着什么 → 我验证了几成 → 下一步。**信息密度不够就会变成注水。**
> - 20 分钟 ≠ 把 10 分钟的稿子念慢。20 分钟**一条主线撑不起来**，必须重新配结构（见下）。

### 1b. 20 分钟长视频的结构（按新时长重配）

| 段 | 时长 | 内容 |
| --- | --- | --- |
| 开场 | 0:00-1:30 | 给具体利益 → 点痛 → 定位 → 期号 |
| **主线深挖** | 1:30-10:00 | 本周最强 1 条信号，**讲透**：背景、机制、数据、传导链、机会与反面 |
| **第二主线** | 10:00-15:00 | 本周第二强信号（同样走完整四层） |
| **跟踪对账** | 15:00-18:00 | 2~3 条已跟踪信号的今日进展 + 到期判断的对账 |
| **方法总结** | 18:00-19:00 | 这一周教会我的判断方法 |
| **结尾** | 19:00-20:00 | 固定对账承诺 + 定位 + 免责声明 |

> **与旧版（10 分钟）的区别**：旧版是「1 主线 + 4 条对账」；20 分钟需要 **2 条主线**，否则单条主线会被迫反复注水。


### 2. 内容结构（每周）
```
1 条主线（本周最强信号，深挖）
+ 2~3 条跟踪（已立档信号的新证据 / 方向变化）
+ 1 段对账（到期预测的验证结果）
```
**上限：1 条主线 + 3 条跟踪。宁可少讲，不可贪多。**
把一周新闻复述一遍 = 把「索引」当正片 = 内容装不下、观众记不住。

### 3. 选材机制
**打分筛，不靠感觉挑**：硬指标 / 有钱 / 新提法 / 推翻直觉 / 传导链清晰（各 1 星）
**入选门槛 ≥4 星**，或属于已跟踪信号的新进展。
落地方式：**每天日报自动打「视频候选」分（0~2 条）**，周末按分数排序取前 1~3 条。

### 4. 核心差异化：公开对账
这是这个号区别于所有同类账号的东西 —— **没人敢公开对账**：
> 「我在 10 月 8 日说过康复设备采购要到 2027 下半年才放量。3 个月后我看到了什么证据、我对了还是错了、我错在哪。」

- 它随时间**自动增值**：第 1 个月没人看，第 12 个月你有 40 条可追溯记录
- 素材来源现成：`signals/` 里每条都带验证方式、时间窗、置信度
- **建议作为系列的起点**，而不是从「每日新闻解读」开始

### 5. 三条禁令（合规与形式）
| 禁令 | 原因 |
| --- | --- |
| ❌ 不出现个股代码、买卖建议、收益承诺 | 视频号金融黑名单、抖音单季处置财经违规 4.5 万条 |
| ❌ 不做「新闻播报」形态 | 采编新闻需资质；定位必须是「个人分析与评论」 |
| ❌ 不全自动出片+多平台分发 | 各平台无统一 API；浏览器自动化违反条款；发布是唯一的合规关口 |

**必做**：标注「内容为个人观点」；用了 AI 画面/配音则标「含有 AI 生成内容」。

## 二、视觉语言（优先级明确）

| 优先级 | 做法 | 为什么 |
| --- | --- | --- |
| ★★★ | **政策原文录屏**（gov.cn 截图 + 关键词高亮） | 权威、可信、零成本；观众爱看「原文长什么样」 |
| ★★★ | **数字卡片动效**（一帧一卡） | 数字是这个号的记忆点 |
| ★★☆ | **时间轴**（今天 → 3M → 12M 与验证点） | 天然适配「趋势判断」，别人抄不走 |
| ★★☆ | **信号档案表格**（signals 的生命周期） | 最强差异化素材 |
| ★☆☆ | **AI 生成画面** | **只用于转场与氛围**，不做主体内容 |

### 为什么 AI 视频生成不做主体
- 你的内容核心是**政策原文 + 精确数字**；AI 模型**不擅长渲染准确的中文字幕与数据图表**，画面与内容无因果关系
- 一旦把「5500 亿」渲染错，**「精确可核对」的人设当场崩塌**
- 正确用法：生成 2~4 秒空镜（工地、货场、数据中心），全片用 3~4 段

| 出处 | 说法 |
| --- | --- |
| 内容节奏设计（10-11） | 「每周一期（1 主线 + 2~3 跟踪，**5~8 分钟**）」 |
