# 参考视频 / 参考截图 放这里

> 用途：把你想要的那种视频风格，喂给 AI 做风格拆解（配色、字体、版式、转场、节奏、声音）。

## 最省事的三步

1. 手机打开抖音 → 搜「掘金之路」→ 进主页
2. 点开 2–3 个视频 → 点「分享」→「复制链接」→ 直接把链接粘贴到对话里
   （也可以复制主页链接，一次就行）
3. 想看转场/节奏：手机录屏 30–60 秒 → 传到电脑 → 存到本文件夹

## 文件放这里

- 录屏：`*.mp4` / `*.mov`
- 截图：`*.png` / `*.jpg`
- 也可以直接放链接：新建一个 `links.txt`，一行一条链接

放好之后跟 AI 说一声「放好了」，它会自动读。
