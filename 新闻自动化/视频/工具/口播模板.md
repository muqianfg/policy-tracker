# 口播模板（每日固定）

## 固定开头（第一句，横竖两版相同）
新闻联播天天有，带你解读最新信号。

## 结构
1. 固定开头 + 日期（"11 月 13 日的新闻联播，主条目 N 条。"）
2. 三件事总览（一句话：这期看三件事：A、B、C）
3. 第一条：术语通俗解释 → 关键数字 → 上下游影响 → 个人影响 → 反面
4. 第二条：同上
5. 第三条：同上
6. 结尾：持续追踪、整理成合集

## 硬性规则
- 不用"今天"，直接说日期
- 不用第一人称"我"
- 视频内不加免责声明
- 字幕单行（横屏 ≤11 字，竖屏 ≤12 字）
- 语速 V4（MiMo 语速快 + atempo 0.88，约 295 字/分）
- 配色 G（米白底 + 酒红 #A3323D）
- 版面不出现"第几期"，页眉只放栏目名 + 日期
- 动效必须有内容对应，没有对应就不做
- 每天出横屏（1920×1080）和竖屏（1080×1920）两版，竖屏单独布局
