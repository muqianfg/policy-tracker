### 1. 2026 版医保目录：新增 107 种药，51 个 1 类创新药创历史新高，CAR-T 进基本医保

- **术语翻译**：
  - **医保药品目录** = 医保**能报销的药**的名单。**进了目录 = 患者能报销、药企能放量**。
  - **1 类创新药** = 中国药品分类里**"全球新"的药**（全新靶点/机制），**含金量最高**。
  - **国谈药** = 通过国家医保谈判降价的创新药（谈判 = 以价换量）。
  - **CAR-T** = 把患者免疫细胞改造后回输、治疗肿瘤的"活药"，**原价常超百万元**。
  - **商保创新药目录** = 商业健康保险的**创新药名单**（与基本医保衔接）。
  - **净增编号** = 调入减调出后的**实际新增数量**（107 调入 - 34 调出 + 剂型合并 = 净增 78）。

- **真信号**（今天快讯 + 国家医保局/人社部 2026-11-14）：

  | 项目 | 内容 |
  | --- | --- |
  | **发布** | 《国家基本医疗保险、生育保险和工伤保险药品目录》及《商业健康保险创新药品目录》（2026 年），**11-14 发布** |
  | **执行** | **2027 年 1 月 1 日**正式落地 |
  | **新增** | **107 种药品**，其中 **51 个 1 类创新药**（**历史新高**） |
  | **调出** | **34 种**（临床价值有限/有更好替代/说明书信息缺失） |
  | **净增与总数** | 净增 **78 个编号**，总数 **3331 个**（西药 1935、中成药 1396）；中药饮片 **885 个** |
  | **重点纳入** | 肿瘤、罕见病、慢性病、精神疾病；**CAR-T（原价超百万元、淋巴瘤）**、**血友病非因子类药物** 首次纳入基本医保 |
  | **商保目录** | 新增 **12 种**（含**全球首个实体瘤 CAR-T**、**中国首个血友病基因治疗药物**）；调整后共 **28 种**；建立商保与基本医保**衔接机制**（2 个 2025 商保品种纳入医保） |

  **为什么这条重要**：**"51 个 1 类创新药 + CAR-T 进医保"是标志性事件** —— 创新药从"自费小众"变成"医保可及"。
  **与 11-10 的四部门"松绑"（不限品种数、不进药费考核）形成闭环**：**进院闸门打开（11-10）+ 支付端纳入（11-14）= 创新药放量的两个前提都齐了。**

- **被推起来的行业**：
  - **直接受益**：**创新药（尤其 CAR-T/基因治疗/罕见病）**、**医药商业与配送**
  - **间接受益**：**DTP 药房与院外承接**、**商业健康保险**、**医药信息化**
  - **被挤压**：**临床价值有限的辅助用药/仿制药**（34 种被调出是信号）

- **机会窗口**：
  - **① 创业风口：钱从哪个环节过**
    - **谁在花钱**：**国家医保局**（支付）、**药企**（进院与推广）、**保险公司**（商保创新药目录）
    - **买什么**：**创新药进院准入与药事服务**、**CAR-T 患者管理与全流程服务**（采集/回输/随访）、**商保创新药产品设计**、**医保信息化**

    - **单笔规模**：CAR-T 单疗程 **百万元级**（医保后大幅下降）；患者管理服务 **几千到几万元/例**；商保产品 **按保费分成**
    - **什么时候**：**2027-01-01 目录执行**是放量起点；**2027 年上半年**是医院进药与医保落地窗口

    - **中游**：医药商业、DTP —— 验证点：**配送量、院外处方**
    - **下游**：商保与患者服务 —— 验证点：**商保创新药保费、理赔**
    - **被挤压方**：临床价值有限的辅助用药/仿制药
    - **相关大宗/期货品种**：无直接品种
    - **概念板块**：创新药、CAR-T、生物医药、商业健康险
    - > ⚠ 仅为业务定位与传导路径分析，**不构成买入/卖出建议，不预测股价**。（**非推荐**）
  - **③ 个人生活：身边会变什么**
    - **能看到/用到的**：**CAR-T 等高价药进医保**（患者自付大幅下降）；**医院能开的创新药更多**
    - **价格与办事**：**国谈药价格降**、**报销比例提高**；**商保产品**覆盖创新药
    - **工作与收入**：**医药准入、患者服务、保险**岗位增加
  - **反面（可能是噪音的理由）**：
    1. **目录执行要等 2027-01-01**：地方落地还有"省级增补/双通道"等环节。
    2. **医保基金压力**：CAR-T 单价高，**纳入后用量会受限（审批/适应症）**。
    3. **51 个 1 类创新药是"数量新高"，不是"销售额新高"**：以价换量。

- **术语翻译**：
  - **先行指标** = **比 GDP 更早反映经济变化的数据**（工程机械开工率、用电量、货运量、投资中标额等）。
  - **工程机械开工率** = 挖掘机/起重机等设备的**实际使用强度**（比"销量"更能反映工地真实开工）。
  - **新基建** = 算力、数据、5G、充电桩等**新型基础设施**。
  - **中标金额** = 项目**招投标成交额**（比"规划"更硬的实物量前兆）。
  - **线下消费者活力指数** = 线下消费活跃度（人流+支付）。

- **真信号**（今天第 7 条 + 国家发改委国家信息中心 2026-11-13）：

  | 指标 | 10 月数据 |
  | --- | --- |
  | **工程机械开工率** | **同比提高 0.7 个百分点，连续两个月同比、环比增速转正** |
  | **区域热度** | **西北**（风光大基地项目开工热度高）；**西南、华南、华东**（交通基建、产业配套提速） |

  | **消费支付** | **10 月各类消费支付金额同比增长 2.6%**；**线下消费者活力指数同比增长 1.8%** |
  | **官方判断** | 四季度稳增长政策发力显效，内需潜力释放，经济运行"稳中向好" |

### 3. 两个新赛道开闸：10 吨级电动商用飞机首飞 + 《汽车改装管理办法》征求意见

- **术语翻译**：
  - **电动商用飞机** = 用电池+电机驱动的民航飞机（**不是无人机**，是可载客的商用飞机）。
  - **CE-25A** = 中国商飞研制的 **10 吨级电动商用飞机**（"E"＝电动，"25"＝按 CCAR-25 适航标准）。
  - **型号合格证（TC）** = 民航局给的"**飞机设计合格证**"，**拿不到 TC 就不能商业运营**。
  - **分布式电推进** = 多个小电机分布在机翼上（效率高、噪音低）。
  - **汽车改装** = 对车辆进行**合法范围内的改动**（外观、内饰、性能）；**一类/二类改装** = 按风险分级管理。
  - **非营运乘用车** = 家用车（**不含出租车/网约车**）。

- **真信号**（今天快讯 + 央广/央视 2026-11-13/14）：

  | 项目 | 内容 |
  | --- | --- |
  | **CE-25A** | 中国商飞研制，**10 吨级电动商用飞机**，**11-14 在山西完成首次有人驾驶智能飞行** |
  | **参数** | **载客 19 人**、最大起飞重量 **10 吨**、巡航速度 **300 公里/小时**、巡航高度 **2400 米**、航程 **400 公里** |
  | **技术** | 分布式电推进；按 **CCAR-25 部**（运输类飞机适航标准）设计 |
  | **进展** | 依托中国商飞与上海交大等研制，**累计开展 19 次飞行试验**；**已向中国民航局提交型号合格证（TC）申请** |
  | **汽车改装** | 《汽车改装管理办法》**公开征求意见**（11-13）：**重点突出"安全""环保"**；面向**非营运乘用车**；实施**一类、二类改装管理**；**二类改装项目需获得汽车企业授权** |
  | **配套** | 国家防总部署凌汛期防凌；川青铁路红原 2 号隧道贯通 |

  **为什么这两条放一起**：**都是"新赛道规则/技术里程碑"** —— 电动飞机是**技术验证**（从 0 到 1），汽车改装是**规则开闸**（从灰色到合法）。
  **对普通人的含义**：**低空经济不再只是"eVTOL 载人"**，**10 吨级电动商用飞机**是"支线航空电动化"的路线；**汽车改装合法化**意味着**后市场（改装件、门店、赛事）**的空间打开。

- **被推起来的行业**：
  - **直接受益**：**电动航空（电池/电机/电控）**、**低空经济基础设施**、**汽车改装件与门店**、**汽车后市场**
  - **间接受益**：**碳纤维与轻量化材料**、**适航认证服务**、**汽车赛事与文旅**
  - **被挤压**：**不合规改装店**（被规则淘汰）、**传统燃油支线飞机**（长期）

- **机会窗口**：
  - **① 创业风口：钱从哪个环节过**
    - **谁在花钱**：**中国商飞与航空产业链**（电动飞机研发/取证）、**地方政府**（低空经济基础设施）、**车企与改装企业**（授权改装）、**消费者**（改装消费）
    - **买什么**：**航空级电池与电机**、**适航认证咨询**、**低空基础设施（起降点/充电）**、**授权改装件与门店服务**、**改装赛事与内容**
    - **谁能接**：航空供应链需**AS9100 等资质**；**改装门店**门槛中等（需授权与资质）；**改装内容/赛事**门槛低（小团队可做）
    - **单笔规模**：电动飞机取证 **亿元级**；改装件 **几百到几万元/件**；改装门店 **几十万元投入**
    - **什么时候**：**电动飞机 TC 取证（2027-2028 年）后才商业运营**；**汽车改装办法正式实施（预计 2027 年）后**市场放量
    - **✅ 最现实的可接点**：**授权改装门店 + 改装内容/赛事**（门槛低、离消费者近，先于飞机商业化落地）
  - **② 投资影响：谁被实质影响（非推荐）**
