### 1. 10 月物价：工厂出厂价 +5.7%，消费者价格只有 +0.7% —— 剪刀差还是没合上

- **术语翻译**：
  - **CPI（居民消费价格指数）** = **老百姓买东西的价格**涨了多少（同比 0.7%）。
  - **PPI（工业生产者出厂价格指数）** = **工厂出厂价**涨了多少（同比 5.7%）。
  - **核心 CPI** = 扣掉**食品和能源**（最容易波动的两项）后的物价，**更能看出真实需求**（同比 0.8%）。
  - **"剪刀差"** = PPI 与 CPI 的差距。**PPI 涨得快、CPI 涨得慢 = 上游涨价，但下游卖不出价** —— 中游制造被夹在中间。
  - **环比 vs 同比**：环比是"比上个月"，同比是"比去年同月"。**看趋势看环比，看水平看同比。**

- **真信号**（今天第 6 条 + 国家统计局 2026-11-09 解读）：

  | 指标 | 10 月数据 | 变化 | 主要拉动/拖累 |
  | --- | --- | --- | --- |
  | **CPI 同比** | **+0.7%** | 涨幅比上月**回落 0.2 个百分点** | 汽油 +22.4%（拉动约 0.63pt）、服务 +0.7%、食品 **-2.9%**（拖累约 0.49pt） |
  | **CPI 环比** | **持平**（上月 +0.2%） | 由涨转平 | 食品 -1.0%（拖累 0.17pt）；汽油 +4.2%（拉动 0.14pt）；黄金饰品 -5.9% |
  | **核心 CPI（扣食品能源）同比** | **+0.8%** | 回落 0.2pt | 数据存储设备 **+45.4%**、平板 +29.3%、计算机 +23.0%、手机 +16.7%（四项拉动约 0.26pt） |
  | **PPI 同比** | **+5.7%** | 涨幅**扩大 0.7pt** | 煤炭 +36.6%、油气 +35.0%、石油煤炭加工 +29.9%、化学原料 +16.4%、计算机通信电子 +5.9% |
  | **PPI 环比** | **+0.7%** | 涨幅**回落 0.5pt** | 6 个能源相关行业合计拉动 0.61pt，**超过总涨幅八成** |

  **三句话读懂**：
  1. **上游涨价（PPI 5.7%）主要来自能源**：煤炭 +36.6%、油气 +35.0% —— 与今年油价、煤价上涨、采暖季预期直接相关。
  2. **下游不涨（CPI 0.7%）**：食品 -2.9%（鲜菜 -16.9%、猪肉 -8.6%）把 CPI 拉下来 0.49pt；**核心 CPI 只有 0.8%**，说明**除食品能源外，需求也不热**。
  3. **唯一的"涨价亮点"是 AI 硬件**：数据存储 +45.4%、平板 +29.3%、计算机 +23.0%、手机 +16.7% —— **这是本轮涨价里唯一由需求驱动的部分**（与 11-07 电商物流"AI 硬件成交额快速上行"互相印证）。

  **对政策的含义**：**CPI 低 = 有政策空间**（降息降准不必担心通胀）；**PPI 高 = 上游利润好、中下游成本压力大** —— 所以政策会继续"扩内需 + 反内卷（治理低价竞争）"。

- **被推起来的行业**：
  - **直接受益**：**煤炭、油气**（价格与利润）、**AI 硬件（存储/消费电子）**（涨价与需求）
  - **间接受益**：**上游资源加工**（有色、化工部分品种）
  - **被挤压**：**中游制造**（成本涨、售价涨不动）、**食品加工**（原料成本与终端价格背离）、**燃油成本高的行业**（航空、物流）

- **机会窗口**：
  - **① 创业风口：不构成创业机会，原因是……**
    - 物价数据是宏观结果，**个人无法"参与"价格本身**（没有可承接的环节）。
    - 唯一可做的是"**利用 AI 硬件涨价周期做渠道**"（见 11-07 万兆光网/AI 质检），但那属于产业侧，不是物价侧。
    - ⚠ **不硬凑。**
  - **② 投资影响：谁被实质影响（非推荐）**
    - **上游**：煤炭、油气 —— 验证点：**长协价、实现油价**
    - **中游**：化工、钢铁、建材 —— 验证点：**价差（原料 vs 产品）**
    - **下游**：食品加工、航空、物流 —— 验证点：**毛利率、燃油成本占比**
    - **被挤压方**：中游制造（成本涨、售价涨不动）
    - **相关大宗/期货品种**：**动力煤（现货无合约）**、**原油（SC，仅观察）**、**甲醇（MA）**、**玉米（C）**
    - **概念板块**：煤炭、石油石化、消费电子、存储
    - > ⚠ 仅为业务定位与传导路径分析，**不构成买入/卖出建议，不预测股价**。（**非推荐**）
  - **③ 个人生活：身边会变什么**
    - **能看到/用到的**：**汽油贵了**（同比 +22.4%）；**菜、猪肉便宜了**（鲜菜 -16.9%、猪肉 -8.6%）；**手机、电脑、存储变贵**（存储 +45.4%）
    - **价格与办事**：**食品便宜、能源贵**，两头拉扯；**黄金饰品**价格回落（-5.9%）
    - **工作与收入**：中游制造企业利润受压 → **涨薪空间小**；上游与 AI 硬件相关岗位景气
  - **反面（可能是噪音的理由）**：
    1. **CPI 低是"食品拖累"造成的**，不是全面通缩 —— 核心 CPI 0.8% 虽低但为正。
    2. **PPI 高是"输入性 + 季节性"**（国际能源价格 + 迎峰度冬），**不代表国内需求强**。
    3. **单月数据波动大**：食品价格受天气影响，**11 月菜价可能反弹**（北方降雪）。
    4. **"剪刀差"已经持续很久** —— 它不是新信号，而是**旧格局的延续**（我们 10-14 就写过）。

### 2. 《中医药传统知识保护条例》公布：2027-01-01 施行，第一次给"老祖宗的方子"上法律保护

- **术语翻译**：
  - **中医药传统知识** = 条例第二条列的五类：**诊疗理论技术、经典名方验方、中药材种植与炮制技术、古籍与传统标记、其他**。
  - **保护数据库** = 国务院中医药主管部门建的**全国统一"知识库"**，知识要"认定"后才进库。
  - **保护名录** = 从数据库里挑出**有代表性、独特性、重要保护价值**的，单列一份名单（最高保护级别）。
  - **知情同意与利益分享** = 别人要用你持有的传统知识，**必须经过你同意、并分给你收益**（这是"知识财产化"的核心条款）。
  - **境外调查禁令** = **境外组织、个人不得在中国境内开展中医药传统知识调查**（违者罚 5 万~50 万元）。
  - **"保护优先、保护与利用相结合"** = 既要保护，也要用起来（临床应用、研究、产业化）。

- **真信号**（今天第 3 条 + 新华社受权发布 2026-11-09 全文）：

  | 项目 | 内容 |
  | --- | --- |
  | **文件** | 国务院令 **第 850 号**；《中医药传统知识保护条例》**2026-09-18 国务院第 97 次常务会议通过**，**李强 2026-10-23 签署公布** |
  | **施行** | **2027 年 1 月 1 日** |
  | **保护范围** | 诊疗理论技术方法、**经典名方验方**、**中药材选育/种植养殖/采集/鉴别技术**、**饮片炮制/制剂配制技术工艺**、**古籍文献与传统标记符号**、其他 |
  | **管理体制** | 国务院中医药主管部门（国家中医药局）负责全国；**县级以上地方中医药主管部门**负责本区域 |
  | **核心制度** | ①**保护数据库**（分类管理）②**保护名录**（专家评审 + 公示 + 发布，可移除）③**申报认定**（个人/组织向省级申报 → 省级初核 → 国务院认定）④**省级调查**（可吸纳医院/高校/企业/协会参与） |
  | **权利与约束** | 持有人享有**传承使用权利** + **知情同意和利益分享权利**；**公共领域知识**由国务院中医药主管部门履行持有人职责；**境外组织个人不得在境内开展调查**（违者罚 **5 万~50 万元**）；涉及国家秘密/商业秘密按相关法律执行 |
  | **推广应用** | 依托**高水平医疗机构**开展临床应用、应用研究、师承教育；**中药饮片炮制技术**与**中药材种植养殖技术**推广应用；支持**数字化收录**古籍与传统知识 |

  **为什么这条值得说**：
  1. **它是"传统知识"第一次有了专门的行政法规** —— 过去中医药保护主要靠"非遗 + 文物 + 专利"拼凑，现在有了**独立的法律工具**。
  2. **最有信息量的是约束条款，不是支持条款**：**境外调查禁令 + 知情同意/利益分享** —— 这两条意味着**中医药知识从"公共资源"变成"可确权、可收费的资产"**。
  3. **时间表明确**：**2027-01-01 施行** → 2027 年上半年是"名录 + 数据库"落地窗口。

- **被推起来的行业**：
  - **直接受益**：**中药饮片与中成药**（炮制技术与经典名方确权）、**中药材种植与良种**（选育技术被保护）、**中医药信息化**（数据库、古籍数字化、知识图谱）
  - **间接受益**：**中医药服务与康养**（品牌与技艺确权）、**中医药文化传播与出版**
  - **被挤压**：**境外机构的中医药"知识采集"**（被禁）；**无来源依据的"秘方"营销**（虚假宣传被约束）

- **机会窗口**：
  - **① 创业风口：钱从哪个环节过**
    - **谁在花钱**：**国家中医药局与省级中医药主管部门**（数据库、名录、调查）、**中医医院与高水平医疗机构**（临床应用与师承）、**中药饮片企业**（炮制技术申报）、**中医药高校与出版社**（古籍整理数字化）
    - **买什么**：**中医药古籍数字化与知识图谱**、**保护数据库/名录管理系统**（申报、认定、公示全流程）、**中药材溯源与种植技术**、**中医师承培训与内容制作**
    - **谁能接**：数据库与知识图谱需**政务信息化经验**；古籍整理需**专业团队**；**内容与培训**门槛低（小团队可做）
    - **单笔规模**：保护数据库系统 **几十万到几百万元**；古籍数字化 **几万到几十万/部**；师承培训 **几千到几万元/人**
    - **什么时候**：**2027-01-01 施行后**进入"名录 + 数据库"建设窗口；省级调查 2027 年上半年启动
    - **✅ 最现实的可接点**：**中医药古籍数字化与知识图谱服务** —— 条例明确"采用数字化技术收录""方便公众查阅"，**这是软件 + 内容结合的小团队活**。
  - **② 投资影响：谁被实质影响（非推荐）**
    - **上游**：中药材种植与良种、中药饮片炮制 —— 验证点：**药材价格、饮片加工量**
    - **中游**：中成药、中医药信息化 —— 验证点：**经典名方品种数、数据库项目中标**
    - **下游**：中医医疗与康养 —— 验证点：**门诊量、连锁中医馆扩张**
    - **被挤压方**：无来源依据的"秘方"营销、境外知识采集
    - **相关大宗/期货品种**：**无直接品种**；间接：中药材（现货）、**玉米（C）**（药材与粮食争地）
    - **概念板块**：中药、中医药信息化、中药材种植、康养
    - > ⚠ 仅为业务定位与传导路径分析，**不构成买入/卖出建议，不预测股价**。（**非推荐**）
  - **③ 个人生活：身边会变什么**
    - **能看到/用到的**：中医馆的**"名方"会标明来源**；**中医药科普内容**变多；**古籍数字化**可在线查
    - **价格与办事**：**经典名方中成药**可能涨价（确权后品牌溢价）；**中医诊疗**服务更规范
    - **工作与收入**：**中医药数字化、古籍整理、师承培训**岗位增加；**中医师**的技艺更有"确权价值"
  - **反面（可能是噪音的理由）**：
    1. **条例是"框架法"**，具体名录、数据库、申报办法**都要等配套文件**（"具体办法由国务院中医药主管部门制定"）。

### 3. 低轨卫星互联网加速组网：千帆在轨 274 颗，一年要打多少颗

- **术语翻译**：
  - **低轨卫星互联网** = 在**离地面几百公里**的轨道上布几千颗卫星，**给地面提供宽带上网**（手机直连、海事、航空、偏远地区）。
  - **千帆星座** = 中国商业低轨卫星互联网星座（上海主导），目标**上万颗**；**星网** = 国家队星座（中国星网）。
  - **"在轨"** = 已经发射上去、正常工作的卫星数量。**在轨数 = 组网进度的唯一硬指标**。
  - **一箭十八星** = 一枚火箭一次送 18 颗卫星上天（批量组网的关键能力）。

- **真信号**（今天第 7 条 + 航天新闻网/CAST）：

  | 项目 | 内容 |
  | --- | --- |
  | **在轨规模** | **千帆星座在轨达 274 颗**（力箭二号遥二"一箭十八星"之后） |
  | **发射方式** | 批量组网：**一箭十八星**，力箭二号等商业火箭承担 |
  | **政策定位** | 已被列入"**六张网**"之一的新一代通信网（11-07 我们写过：万兆光网 136 个试点、6G 到 2029 年） |
  | **配套快讯** | **前 10 个月国开行发放制造业贷款超 4800 亿元**；**140 多家企业及机构提前续约第十届进博会** |
  | **对照** | 手机直连卫星技术"**已完成实测验证**"（11-07 口径）→ **商用还差终端与资费** |
