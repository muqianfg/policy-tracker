# 术语对照表（说人话版）

> **为什么有这个文件**：这个项目面向普通人。**任何人话表达里第一次出现专业词，必须先用一句话解释它是什么、跟普通人有什麼关系，之后才能用简称。**
> 用法：写日报、写视频脚本、写公开摘要时，对照本表；表里没有的新词，按同样标准补进去。

## 三档解释规则（2026-10-16 确立）

同一个专业词，在**三个不同场景**里的解释规则不一样 —— 因为读者的处境不同：

| 场景 | 规则 | 为什么 |
| --- | --- | --- |
| **日报** `日报/` | **当天第一次出现就解释** | 日报是**独立**的一天，读者可能只看这一天 |
| **信号档案** `信号/` | **整个档案第一次出现解释，之后不再解释** | 档案是**累积**的，从标题读到末尾只会遇到一次 |
| **口播稿** | **讲到哪就解释到哪** —— 不管之前解释过几次 | 视频是**线性的**，观众不可能往前翻；每一期都是新观众 |

> 一句话：**文字内容按「第一次」算，视频内容按「每一次」算。**
> 视频里解释的时机很重要：**讲到那个词的时候顺手解释**，不要提前堆在开头（那样观众记不住，也打断了节奏）。

### 信号档案里的解释放哪

两个位置任选，优先第一个：
1. **标题里**（最显眼，且不打断正文）—— 例：`# T-20261015-01 · 绿证（绿色电力证书：证明「我用的电是绿电」的一张凭证）跨境交易 → …`
2. **正文第一次出现处** —— 格式：`以旧换新（买新的、旧的国家给补贴）补贴资金节前落地`

每个信号文件顶部都有一行术语指引，指向本表。

## 一条铁律

❌ **错误**：「PPI 连涨七个月，而 CPI 只有 0.9%」
✅ **正确**：「**工厂的出厂价格**（专业叫法是 PPI）已经连涨七个月……而**老百姓买东西的价格**（CPI）只涨了 0.9%」

**判断标准**：把这句话念给一个不看财经新闻的人听，他能听懂吗？听不懂就是没解释。

## 一、经济数据类

| 专业词 | 一句话人话 | 为什么跟普通人有关 |
| --- | --- | --- |
| **CPI**（居民消费价格指数） | **老百姓买东西的价格**涨了多少 | 决定你的钱贬值有多快、存款利息够不够抵 |
| **PPI**（工业生产者出厂价格指数） | **工厂出货的价格**涨了多少 | 它是物价的"上游"：工厂涨价，早晚会传到货架上（也可能先压死中间商） |
| **社融**（社会融资规模） | **整个社会借了多少钱**（含银行贷款、政府发债、企业发债等） | 借钱多说明经济在扩张；但要拆开看**是谁在借** |
| **M1 / M2** | **M2 = 所有存款的总量；M1 = 其中能马上花的活钱** | 两者差距大，说明钱在账上趴着没流动 |
| **CPI 与 PPI 剪刀差** | **工厂在涨价、商店涨不动** | 夹在中间的企业最难受：成本升、售价提不上去 |
| **住户存款** | **老百姓存进银行的钱** | 存款猛增而利率很低，说明大家不敢花、也没好地方投 |
| **广义货币 / 狭义货币** | 同 M2 / M1 | — |

## 二、财政与债务类

| 专业词 | 一句话人话 | 为什么跟普通人有关 |
| --- | --- | --- |
| **特别国债** | **国家为了特定用途单独借的一笔钱**（不算常规预算） | 它的用途就是接下来钱的流向 |
| **一般债 / 专项债** | 地方政府借的两种钱：**一般债补日常开支，专项债干具体项目** | 专项债投向哪，哪就有工程和订单 |
| **结存限额** | **以前批准但没用完的借钱额度** | 拿出来用=不新增额度也能多花钱 |
| **超长期国债** | 借期特别长的国债（10 年以上） | 反映国家对长期利率的判断 |
| **化债 / 清欠** | **把欠企业、欠工程队的钱还上** | 如果你或你的客户被政府/国企欠款，这直接关系到回款 |
| **财政加杠杆** | **政府多借钱来花** | 与"企业/居民少借钱"相对照，能看出谁在撑经济 |

## 三、金融与市场类

| 专业词 | 一句话人话 | 为什么跟普通人有关 |
| --- | --- | --- |
| **社融存量 / 增量** | **累计借了多少钱 / 这一段时间新借了多少** | 存量看规模，增量看势头 |
| **直接融资 / 间接融资** | **直接融资=企业自己发债发股票拿钱；间接融资=通过银行借钱** | 前者强说明市场在起作用，后者弱说明银行在收缩 |
| **TCO**（全生命周期成本） | **买来 + 用 + 修 + 报废，总共花多少钱** | 判断电动车划不划算，不能只看买车价 |
| **REITs** | **把一栋楼、一条公路的收租权拆成小份卖给普通人** | 让普通人能投资基础设施分红 |
| **集采**（集中带量采购） | **国家替全国医院统一砍价买药买耗材** | 药价降，但药企利润被压 |
| **LPR** | **银行贷款的基准利率报价** | 决定房贷、经营贷利息高低 |

## 四、医疗与民生类

| 专业词 | 一句话人话 | 为什么跟普通人有关 |
| --- | --- | --- |
| **医共体**（紧密型县域医共体） | **把县医院、乡镇卫生院、村卫生室绑成一个整体，让农民在县里就能看好病** | 决定基层能不能看上病、也决定医疗资源往哪投 |
| **分级诊疗** | **小病在社区、大病去大医院，别都挤三甲** | 靠的是转诊系统，不是口号 |
| **强基工程**（医疗卫生强基工程） | **给基层医院（县、乡、村）补短板：人、设备、钱** | 基层医院是主要采购方 |
| **防治康管全链条** | **从预防、治疗、康复到长期管理，一条龙** | 康复和慢病管理是个人可进入的领域 |
| **康复护理** | **大病或手术之后的恢复、长期照护** | 床位、治疗师都被政策点名要扩 |
| **"一老一小"** | **老人和小孩的健康服务** | 政策与采购的固定优先项 |
| **上门服务费** | **医护人员上门做护理可以单独收费** | 网约护理、居家照护能定价变现的依据 |

## 五、产业与政策类

| 专业词 | 一句话人话 | 为什么跟普通人有关 |
| --- | --- | --- |
| **新质生产力** | **靠技术和效率赚钱，而不是靠堆人力堆资源** | 资源会往技术型行业倾斜 |
| **专精特新** | **在某个细分领域做得特别好的中小企业** | 政策支持的常见对象 |
| **内卷式竞争 / 无序非理性竞争** | **大家都不赚钱地互相压价** | 被点名整治后，龙头受益、靠低价活的小厂受损 |
| **以旧换新** | **买新的，旧的国家给补贴** | 家电、汽车销量的直接推手 |
| **设备更新** | **企业换新机器，国家给支持** | 工业设备订单来源 |
| **六张网** | **水网、电网、算力网、通信网、地下管网、物流网** | 今年基建投资的总框架，超 7 万亿规模 |
| **实物工作量** | **真的开工干活了，不只是签了约** | 判断基建真假的标准：看花了多少钱、货有没有动 |
| **耐心资本 / 长期资金** | **不急着套现、能拿五年十年的钱**（如社保、保险资金） | 决定股市里有没有稳定买盘 |
| **低空经济** | **把 1000 米以下的天空用起来**（无人机、飞行汽车等） | 配套基建可能先于整机放量 |
| **eVTOL**（电动垂直起降飞行器） | **能垂直起飞的电动小飞机** | 低空经济的主力机型 |
| **具身智能** | **有身体的人工智能**（机器人） | 与脑机接口同为被点名的未来产业 |
| **脑机接口** | **把大脑信号直接连到机器上** | 康复医疗是最先落地的场景 |
| **丝路电商** | **面向"一带一路"国家的跨境电商** | 外贸新渠道 |

## 六、技术类

| 专业词 | 一句话人话 | 为什么跟普通人有关 |
| --- | --- | --- |
| **HIS**（医院信息系统） | **医院里的挂号、收费、病历系统** | 医院信息化采购的主要标的 |
| **影像云 / 检查互认** | **拍的片子存到网上，换医院不用重拍** | 分级诊疗的技术前提 |

| **CDMO / CRO** | **帮药企和器械公司做研发与生产的第三方公司** | 创新器械上市链条上的服务商 |

## 维护规则

- 每天运行日报时，若出现本表未收录的专业词，**必须**：① 在当天日报里先解释再用；② 把该词补进本表。
- 视频脚本里第一次出现专业词，写成「**人话叫法**（专业叫法是 XX）」的格式，之后统一用简称。
- 本表是公开文件，任何看到的人都可以指出没解释清楚的词。
