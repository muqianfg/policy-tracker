| 专业词 | 人话解释 |

| **国常会（国务院常务会议）** | 国务院**每周例会**，定政策方向（最实的内阁会议） |
| **资本市场投融资综合改革** | 同时改**"融资端"**（IPO/再融资）与**"投资端"**（中长期资金入市/投资者保护） |

| **中长期资金** | 险资、社保、年金等**长期持有**的钱 |

## 一、问题（可被证伪）

国常会研究"持续深化资本市场投融资综合改革"后，2027 年上半年，会不会出台资本市场改革的具体方案/文件（IPO 节奏、再融资、中长期资金入市、分红回购 至少 2 项有实质安排）？

## 二、我的答案

**会出台具体方案（概率高），且至少 2 项有实质安排。**

1. 2027 年上半年**证监会/国务院层面出台改革文件**；
2. **中长期资金入市（险资/社保提高权益比例）**最可能先落地；
3. **IPO 节奏**会更"逆周期调节"（市场差就放缓）。

理由：**国常会研究 = 后续必有文件**；投资端改革是当前市场核心诉求。

一句话：**"文件会有、节奏看市场"**。

## 三、验证方式

- **主指标**：证监会/国务院资本市场改革文件
- **辅助指标**：中长期资金权益配置比例变化
- **判据**：
  - 2027-06-30 前有改革文件 **且** ≥2 项实质安排 → **成立**
  - 无文件 → **推翻**
