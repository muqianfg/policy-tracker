## 术语小词典（本档案用到的人话解释）

| 专业词 | 人话解释 |
| --- | --- |
| **区域电力市场** | 几个省的电放在一个池子里集中买卖，而不是各省自己管内 |
| **现货市场** | 按当天实际供需实时定价，类似蔬菜的当日行情 |
| **辅助服务市场** | 买卖调频、备用这类支撑电网稳定的服务 |
| **出清** | 集中撮合后定出成交价与成交量 |
| **独立储能** | 不属于某个电站、单独建在电网侧、可直接参与市场交易的储能电站 |
| **输电权** | 使用某条跨省输电通道的权利，可以竞价取得 |

## 一、问题（可被证伪）

南方区域电力市场转入正式运行后，「调节资源侧将容纳新型储能参与现货及辅助服务交易」，会不会在 2027 年内带来储能参与市场的可观测规模（以参与市场的储能装机或辅助服务补偿金额衡量）？

## 二、我的答案

会，但**规模先小后大，2027 年内仍以试点与少量项目为主**。依据：① 政策口径已明确，这是**商业模式的确立**，不只是口号；② 但参与需要**技术条件（计量、通信、调度接入）与结算规则**，正式运行初期不可能完善；③ 更现实的是**能参与的第一批是「独立储能电站」**，而不是用户侧储能 —— 因为独立储能才有资格直接交易。判断：2027 年内会看到广东、云南等省的一批独立储能电站进入市场，辅助服务补偿金额从零到有，但占储能总收入比例不会超过 20%。

## 三、验证方式

- 南方能监局 / 五省区电力交易中心发布的**储能参与市场细则与首批名单**
- **辅助服务费用的月度结算金额**（交易中心会公布）
- 独立储能电站的**年利用小时数与收入结构**（现货套利 / 辅助服务 / 容量租赁）
- **判据**：若 2027 年内无任何储能参与市场的公开结算数据，判断被推翻

## 四、证据时间线（只追加，不改写）

### 2026-10-24 · 立档

- **来源**：《新闻联播》快讯 + 新华社（2026-10-24，广州）
- **事实**：
  - **我国首个区域电力市场 —— 南方区域电力市场，10 月 24 日从试运行转入正式运行**（在广州举行推进会）
  - 覆盖 **广东、广西、云南、贵州、海南五省区**；自 2025 年 6 月启动连续结算试运行，历经一年多极端工况检验
  - 体系：**中长期交易为基础、现货市场为导向、辅助服务市场为调节**；**煤电、水电、核电、风电、光伏全类型电源在统一规则下出清定价**；跨电网经营区输电通道实现**输电权竞价配置**
  - 硬数据（1—9 月）：累计交易电量**近 9000 亿千瓦时**，占全网售电量**超七成**；新增售电量中**四成来自新能源**；**最大单日出清电量超 40 亿千瓦时**；市场主体注册**突破 29 万家**；新能源利用率保持 **95% 以上**、**成为全网第一大电源**；跨经营区交易电量 **194 亿千瓦时**
  - **下一步三条**：电源侧丰富新型主体参与模式；**需求侧面向用户逐步放开规模**；**调节资源侧将容纳新型储能等更多品类参与现货及辅助服务交易**
- **我的解读**：**这句话确立了储能靠什么赚钱的商业模式**。此前储能主要靠容量租赁与峰谷价差，收入单一且政策依赖强；进入市场后可同时赚「现货套利 + 辅助服务」两份钱
- **对判断的影响**：立档

## 七、影响判断（三分法，缺一不可）

### 2026-10-24 · 影响判断

#### 一、创业风口：钱从哪个环节过

| 要素 | 内容 |
| --- | --- |
| **谁在花钱** | 南方电网、五省区电力交易中心、售电公司、工商业用电大户 |
| **买什么** | 售电代理与电力交易咨询、储能参与辅助服务的聚合平台、需求侧响应系统、电力计量与通信装置 |
| **谁能接** | 门槛在**资质与关系**（电力交易资质、与交易中心对接），不在技术；储能聚合需要调度接入许可 |
| **单笔规模** | 售电代理按度电抽佣（薄利但量大）；储能聚合与虚拟电厂项目百万级 |
| **什么时候** | **正式运行后 6~12 个月**，等细则与结算规则稳定 |

#### 二、投资影响：谁被实质影响（**非推荐**）

| 环节 | 受影响主体（按业务归类） | 为什么受影响 | 财报里要验证什么 |

- **相关大宗/期货**：**动力煤**（煤价下跌→电价下行→高耗能受益；国内无直接合约，看现货价格）；无其他直接品种
- **概念板块**：电力市场 / 储能 / 虚拟电厂

#### 三、个人生活：身边会变什么

- **电价会开始出现「时间差价」** —— 白天贵、夜里便宜，洗衣机与充电可以挑时段省钱
- **居民电价短期不会大变**（本次明确「需求侧逐步放开」，居民在最后）
- **分时电价的档位会变多**，电费单会比现在复杂
- 装了屋顶光伏的家庭，**余电上网价格会更贴近市场**（可能更低，也可能更高）
- 小区附近可能出现**储能电站**（电网侧储能），外观像集装箱
