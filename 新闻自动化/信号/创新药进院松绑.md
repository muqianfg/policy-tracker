## 术语小词典（本档案用到的人话解释）

| 专业词 | 人话解释 |
| --- | --- |
| **创新药** | 新研发、有专利保护的药（**不是仿制药**） |
| **进院** | 医院把它列入用药目录、医生能开 |
| **药事会** | 医院里决定"进哪些药"的委员会（**药品进院的闸门**） |
| **"总药品品种品规数量限制"** | 过去医院有"最多能有多少种药"的限制 → 新药进不来，要"进一个、出一个" |
| **"绩效监测指标"** | 医院考核里看"门诊/住院人均药费涨多少" → 创新药贵，医院怕超标就不敢用 |
| **国谈药** | 通过国家医保谈判降价的创新药（医保报销） |
| **DTP 药房** | 专门承接新特药处方的院外药房 |

## 一、问题（可被证伪）

四部门发文给创新药"松绑"（不限品种数、不纳入药费增幅绩效监测）后，2027 年底前，创新药在二级以上医院的配备会不会明显放量？

## 二、我的答案

**会明显放量，但要到 2027 年下半年才看得清。**

我判断：
1. **2027 年 6 月底前，至少 20 个省份**出台创新药进院配套细则；
2. **2027 年创新药（含国谈药）销售额增速 ≥15%**（高于医药行业整体）；
3. 但**医保基金总额约束仍在**，放量是"结构调整"（创新药替代辅助用药），不是"总量扩张"。

理由：① 文件把"进院三道闸"松了两道半（品种数、绩效监测、药事会），**医院端政治风险显著下降**；② 但各省细则、医院药事会节奏、医保支付能力决定落地速度；③ 历史经验：政策松绑到处方放量通常 2~4 个季度。

## 三、验证方式

- **主指标**：各省卫健委/医保局的进院配套文件数量（2027-06-30 前 ≥20 省）
- **辅助指标**：创新药（国谈药）销售额增速（IQVIA/医保局数据）
- **判据**：
  - 2027 年增速 ≥15% 且配套省份 ≥20 → **成立**
  - 增速 <8% → **推翻**

## 四、证据时间线（只追加，不改写）

### 2026-11-10 · 立档

- **来源**：
  - 今天《新闻联播》快讯"我国加强创新药安全合理配备使用"
  - 央视新闻 2026-11-10《四部门发文：加强创新药安全合理配备使用》
- **事实**：
  - **国家卫生健康委、国家医保局、国家中医药局、国家疾控局**发布《关于进一步做好创新药安全合理配备使用工作的通知》
  - **① 进院**：二级以上医疗机构优化创新药进院制度和工作流程，及时召开**药事会**，及时纳入本机构用药目录；省市医院逐级示范
  - **② 培训与指南**：用药知识与医保支付政策培训；编写**创新药临床使用专家共识**；将循证证据充分的药品纳入**临床诊疗指南**
  - **③ 价格与保障**：落实**药学类相关医疗服务价格项目**，优化使用政策环境
  - **④ 松绑（最关键）**：**不对医疗机构总药品品种品规数量进行限制**；**有关创新药不纳入门诊次均药品费用增幅、住院次均药品费用增幅等公立医疗机构绩效监测指标**
- **我的解读**：
  - **过去创新药进院有三道闸：品种数限制、药事会拖着不开、药费增幅考核。今天一次性松掉两道半。**
  - **对医院**：进药的"政治风险"下降；**对药企**：放量的"最后一公里"被打开。
  - **但医保总额约束仍在** → 放量是"结构调整"，不是"总量扩张"；辅助用药与无临床价值仿制药被挤压。
- **对判断的影响**：**立档**

### 2026-11-14 · 增强（支付端闭环）：2026 版医保目录新增 107 种、51 个 1 类创新药、CAR-T 进医保

- **来源**：今天《新闻联播》快讯；国家医保局/人社部 2026-11-14 发布。
- **事实**：2026 版医保目录**新增 107 种药**（其中 **51 个 1 类创新药**、历史新高）；**调出 34 种**；净增 78 个编号、总数 3331 个；**CAR-T（原价超百万元、淋巴瘤）、血友病非因子类药物首次纳入基本医保**；**商保创新药目录新增 12 种、共 28 种**；**2027-01-01 执行**。
- **我的解读**：**"进院松绑（11-10）+ 支付端纳入（11-14）"两个前提同时具备** —— 这是过去"政策热、放量慢"缺的一环。**创新药放量的闭环成立了。**
- **对判断的影响**：**增强**（支付端证据加入）

#### 一、创业风口：钱从哪个环节过

| 要素 | 内容 |
| --- | --- |
| **谁在花钱** | **二级以上医院**（药事会、用药目录、信息化）、**药企**（进院推广、真实世界研究）、**地方医保局**（支付政策培训） |
| **买什么** | **创新药进院准入服务**（医院准入策略、药学服务）、**药事管理与合理用药系统**、**真实世界研究与循证材料**、**DTP 药房与患者服务** |
