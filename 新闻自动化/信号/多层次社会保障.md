## 术语小词典（本档案用到的人话解释）

| 专业词 | 人话解释 |
| --- | --- |
| **多层次社会保障体系** | **国家保基本 + 单位补充（企业年金）+ 个人储备（个人养老金/商业保险）** 三层 |
| **企业年金** | 企业给员工**额外办的养老金**（非强制），目前覆盖面小 |
| **个人养老金** | 个人自愿开账户、**享受税收优惠**的养老投资（每年上限 1.2 万元） |
| **长期护理保险（长护险）** | 为**失能老人**护理费用提供保障（"第六险"），目前是试点 |
| **灵活就业人员社保** | 外卖骑手、网约车司机、自由职业者等的养老/医疗保险（**缴费全自付，参保率低**） |
| **职工养老保险全国统筹** | 养老金**全国统收统支**（解决地区不平衡） |

## 一、问题（可被证伪）

李强专题学习社会保障后，2027 年底前，长期护理保险会不会出台全国性文件（从试点转向全面实施），且个人养老金推出更有吸引力的扩围政策？

## 二、我的答案

**会：长护险出台全国性制度文件（概率高），个人养老金会扩围（提额度或扩大产品），但两者都不会"一步到位"。**

1. 2027 年底前，**长护险国家层面制度文件出台**（人社部/医保局），从"试点"转为"全面实施"；
2. **个人养老金年度缴费上限提高或税优加码**（至少一项）；
3. 但**灵活就业社保参保率**只是"逐步提高"，不会有强制。

理由：① 专题学习由郑功成讲解、三位国务委员/副总理交流，**规格高**；② 长护险已在 49 个城市试点多年，**全国推开是"十五五"既定方向**；③ 个人养老金"开户多、缴存少"，**必须提高吸引力**。

## 三、验证方式

- **主指标**：人社部/国家医保局关于长护险的全国性文件
- **辅助指标**：个人养老金制度调整公告（缴费上限/税优）
- **判据**：
  - 2027 年底前长护险全国文件 **+** 个人养老金至少 1 项扩围 → **成立**
  - 两者都无 → **推翻**

## 四、证据时间线（只追加，不改写）

### 2026-11-12 · 立档

- **来源**：
  - 今天《新闻联播》第 2 条"李强主持国务院第二十二次专题学习"
  - 新华社 2026-11-12 全文
- **事实**：
  - 学习主题：**"健全多层次社会保障体系，进一步织密扎牢社会保障安全网"**
  - 讲解人：中国人民大学教授**郑功成**；何立峰、刘国中、谌贻琴交流发言
  - 要求：健全**覆盖全民、统筹城乡、公平统一、安全规范、可持续**的多层次社保体系
  - **补充层**：扩大**企业年金**覆盖面；提高**个人养老金**制度吸引力；支持**商业健康保险**；**稳妥有序推进长期护理保险制度建设**
  - **重点群体**：完善**灵活就业人员**社保制度、**逐步提高参保率**；加强**新就业形态人员**权益保障
  - **公平托底**：稳步提高城乡居民养老保障水平；发挥失业保险功能；健全分层分类社会救助
  - **可持续**：职工养老保险**全国统筹**；基本医保**省级统筹**；社保基金安全监管与保值增值
  - **法治**：修订完善社会保障相关法律法规
- **我的解读**：
  - **社保改革第一次把"补充层"和"灵活就业"放到同一张清单** —— 过去是"保基本"，现在是"保基本 + 扩补充 + 补新业态"。
  - **对个人（尤其自由职业者）**：灵活就业社保参保率要"逐步提高" → 未来可能有补贴或简化；个人养老金吸引力要提高 → 税优或产品会变。
  - **长护险是"服务侧"机会**：全国推开后，**失能评估与护理服务**是硬需求。
- **对判断的影响**：**立档**
