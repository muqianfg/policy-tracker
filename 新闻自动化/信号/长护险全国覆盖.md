## 术语小词典（本档案用到的人话解释）

| 专业词 | 人话解释 |
| --- | --- |
| **长期护理保险（长护险）** | 为**失能老人**的护理费用提供保障的"**第六险**"（养老/医疗等之外） |
| **长期照护师** | 专门做失能照护的**新职业**（评估+护理） |
| **基本全覆盖** | 全国**绝大多数地市**都有长护险（不是"人人都有待遇"） |
| **失能人员** | 生活不能自理的老人（吃饭/洗澡/穿衣都需要人帮） |

## 一、问题（可被证伪）

长期护理保险"2028 年底基本实现全国全覆盖"目标明确后，2027 年底前，全国长护险参保人数会不会 ≥4 亿人，覆盖地市数会不会 ≥90%（约 300 个地市）？

## 二、我的答案

**参保 ≥4 亿会成立（2028 全覆盖前会快速扩面），覆盖地市 ≥90% 偏乐观（我给 80%）。**

1. 2027 年底前参保人数 **4~4.5 亿**（当前 3.2 亿 + 扩面）；
2. 覆盖地市 **80%~90%**（约 270~300 个）；
3. 但**护理服务供给**（护理员/机构）跟不上，会出现"有保险没服务"。

理由：**2028 全覆盖是硬目标**，地方会加速扩面；但**护理员短缺**是瓶颈。

一句话：**"保险铺得快、服务跟不上"**。

## 三、验证方式

- **主指标**：国家医保局年度统计（参保人数、覆盖地市）
- **判据**：
  - 2027 年底前参保 ≥4 亿 **且** 覆盖地市 ≥90% → **成立**
  - <3 亿 → **推翻**
