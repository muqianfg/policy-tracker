## 术语小词典（本档案用到的人话解释）

| 专业词 | 人话解释 |

| **核能综合利用** | 核电站不只发电，还把核能用于**供暖、工业供汽、海水淡化**，一份燃料用出几份收益 |
| **"暖核一号"** | 山东海阳核电的**核能供热**工程代号，我国首个核能供热商用项目 |
| **核能工业供汽** | 用核电站的高温蒸汽**直接供应石化、化工园区**，替代燃煤锅炉 |
| **核技术应用产业** | 把核技术用于**医疗（放疗/影像）、工业检测、辐照加工、育种**等 |
| **热效率** | 一份热能里有多少被真正用上。核电发电效率约 35%，转为供汽可达 70%+ |
| **吉焦** | 热量单位，1 吉焦约等于 34 公斤标准煤的热值（粗算） |

## 一、问题（可被证伪）

核能综合利用推进后，2027 年底前，"暖核一号"（海阳核电）的核能供热面积会不会从 1350 万平方米扩到 2000 万平方米以上？

## 二、我的答案

**会。** 2027 年底前，"暖核一号"供热面积 **≥2000 万平方米**，且**核能供热新增城市 ≥2 个**。

理由：
1. 海阳核电 **3、4 号机组预计 2027 年投产**，"暖核一号"供热能力会随机组扩容；
2. 核能供热成本低于燃煤（海阳取暖费已从 **22 元/㎡降到 21 元/㎡**），地方政府有动力扩面；
3. 国家电投在胶东半岛的规划已明确"远期为 2 亿平方米"。

## 三、验证方式

- **主指标**：国家电投/山东核电的年度供暖季新闻（供热面积口径）
- **辅助指标**：① 海阳核电 3、4 号机组投产时间；② 核能供热新增城市名单
- **判据**：
  - 2027 年底前 **≥2000 万㎡** → **成立**
  - 仍 **<1600 万㎡** → **推翻**

## 四、证据时间线（只追加，不改写）

### 2026-11-07 · 立档

- **来源**：
  - 今天《新闻联播》第 6 条"我国加快推进核能综合利用"
  - 第一财经/国家电投 2026-10-29《从发电到取暖、供汽，核能"重器"如何实现"多点开花"》
- **事实**：
  - **"暖核一号"（海阳核电）**进入**第八个供暖季**，为海阳、乳山 **40 万居民、1350 万平方米**提供零碳供暖
  - 累计供热 **1973 万吉焦**、节约原煤 **178 万吨**、减排 CO2 **325 万吨**、SO2 **2.1 万吨**
  - 核能供热后，海阳居民取暖费从 **22 元/㎡ 降至 21 元/㎡**
  - **工业供汽（田湾核电）**："核能+石化"供汽项目 2024-06 投产，每年供工业蒸汽 **480 万吨**，年省碳指标 **70 万吨**
  - **效率对比**：核电发电效率约 35%，转供汽热效率可达 **70% 以上**
  - **核技术应用**：《核技术应用产业高质量发展三年行动方案（2024—2026）》提出到 **2026 年直接经济产值 4000 亿元**
  - 预计 **2027 年**海阳核电 3、4 号机组投产后供热能力进一步扩展
- **我的解读**：
  - **商业逻辑变了**：过去核电站只卖电（35% 效率），现在卖热、卖汽（70% 效率），**同样的反应堆，产出翻倍**。这是核电企业的第二增长曲线。
  - **但它是"点"不是"面"**：1350 万平方米在全国（约 100 亿平方米）里占比极小，**是样板，不是主流**。
  - **核能供热受物理约束**：长距离输送有热损，**只能在核电站周边 30~50 公里内**发展，不可能全国铺开。
- **对判断的影响**：**立档**

#### 一、创业风口：钱从哪个环节过

| 要素 | 内容 |
| --- | --- |
| **谁在花钱** | **核电集团**（国家电投、中核、中广核）、**地方政府与热力公司**（核能供热管网）、**石化园区**（工业蒸汽） |
| **买什么** | **长距离供热管道与保温管**、**换热站与热计量设备**、**核能供汽的蒸汽管网与阀门**、**工业余热利用** |
| **谁能接** | 管网施工需**市政/压力管道安装资质（GB 类）**；设备是**制造业订单**；**热计量与换热站运维**可由地方服务商承接 |

#### 三、个人生活：身边会变什么

- **能看到/用到的**：北方部分城市**用核能供暖**（海阳、乳山已实现）；**取暖费略降**；工业蒸汽替代燃煤后**空气更好**
- **价格与办事**：**供暖价格更稳**（不受煤价波动影响）；核能供热城市增加
- **工作与收入**：**核电、供热管网、核医疗**岗位增加
