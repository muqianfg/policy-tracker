## 术语小词典

| 专业词 | 人话解释 |
| --- | --- |
| **装机容量** | 发电设备的名义能力。一台 100 万千瓦的机组，指它满负荷时的能力 |
| **发电量** | 实际发了多少电。光伏只有白天发、风电看风，「装机大」不等于「发电多」 |
| **利用小时数** | 一年实际发电量 ÷ 装机容量。光伏约 1,200~1,500 小时，煤电约 4,500 小时，差 3 倍 |
| **液态空气储能** | 用富余的电把空气冷却成液体存起来，需要电时让它气化推动发电机。本质是「把电存成冷能」 |
| **往返效率** | 存进去 100 度电，能取出来多少度。液态空气约 50~60%，抽水蓄能约 75%，锂电池 85%+ |
| **转动惯量** | 电网的「惯性」，靠大型旋转机械提供。新能源多、传统机组少 → 电网容易不稳 |

## 一、问题（可被证伪）

可再生能源「装机占比 60.94% vs 发电量占比 41.8%」的缺口，未来 2 年能否明显缩小？

## 二、我的答案

**不能明显缩小，会维持在 18~20 个百分点。**

理由：这个缺口不是「问题」，是风光发电的物理特性决定的。只要新增装机继续以风光为主（目前占新增 67.6%），缺口就会维持甚至扩大。**储能能缓解波动，但不能提高风光的年发电量**（存的是同一度电，还有损耗）。

## 三、验证方式

- **主指标**：国家能源局季度发布会数据，算「装机占比 − 发电量占比」的差值
- **判据**：
  - 2028 年底缺口缩到 15pt 以内 → 我低估了利用小时数改善
  - 缺口扩到 22pt 以上 → 新增装机仍在加速铺风光
  - 维持 18~20pt → 判断成立

## 四、证据时间线（只追加，不改写）

### 2026-10-31 · 立档

- **来源**：国家能源局 2026-10-30 新闻发布会，《人民日报海外版》2026-10-31 第 4 版；今天《新闻联播》联播快讯播报。
- **事实**：
  - 前三季度可再生能源发电量 **3.13 万亿千瓦时，+8%**，占全部发电量 **41.8%**
  - 截至 9 月底可再生能源装机 **25.18 亿千瓦，+14.6%**，占总装机 **60.94%**
  - 风光装机 **20.1 亿千瓦（占 48.66%）**；风光发电量 **1.92 万亿千瓦时（+11%，占全社会用电量 23.8%）**
  - 新增装机：可再生能源 **1.8 亿千瓦占 71.7%**；风光 **1.7 亿千瓦占 67.6%**
  - **可再生能源发电增量超 2,500 亿千瓦时，占全国发电增量的 87.5%**
  - 里程碑：**光伏发电装机历史性超过煤电，成为装机规模最大的电源品种**
- **我的解读**：**装机 60.94% 却只发 41.8% 的电，风光 48.66% 只发 23.8% —— 这就是储能的全部理由。** 但必须说清：这不是「效率低」，是风光的天性。**储能解决的是「什么时候发」，不是「发多少」。**
- **对判断的影响**：**立档**

## 七、影响判断（三分法）

### 2026-10-31 · 影响判断

#### 一、创业风口：钱从哪个环节过

| 要素 | 内容 |
| --- | --- |
| **谁在花钱** | 五大发电集团、地方能源集团、中国绿发等央企、电网公司 |
| **买什么** | 储能电站运维服务、深冷设备检维修、**储能项目前期咨询与并网手续代办** |
| **谁能接** | 设备制造需重资产；**运维与咨询门槛低**（懂电力系统 + 会写材料）；深冷检维修需**特种设备资质** |
| **单笔规模** | 储能电站运维 **年费百万级**；并网咨询单项目 **几十万** |
| **什么时候** | **2026 Q4 ~ 2027 年，配储要求推动项目集中开工** |

**✅ 最现实的可接点**：**储能电站并网手续代办与前期咨询** —— 每个项目都要做，流程复杂（涉及电网、能源局、消防），熟悉流程的人很少，单价高。

#### 二、投资影响：谁被实质影响（**非推荐**）

> ⚠ 仅为业务定位与传导路径分析，**不构成买入/卖出建议，不预测股价**。

| 环节 | 受影响主体 | 为什么受影响 | 财报里要验证什么 |
| --- | --- | --- | --- |
| 上游 | 储能集成商、压缩机、膨胀机、换热器 | 储能订单增长 | 订单增速、毛利率 |
| 中游 | 发电集团、独立储能运营商 | 容量电价与调峰收入 | 利用小时数、容量电价收入 |
| 下游 | 电网、数据中心、工业企业 | 峰谷价差、用电成本 | 峰谷价差、用电成本 |
| **被挤压方** | 煤电 | 基荷地位下降（但调峰价值上升） | 煤电利用小时数 |

- **相关大宗/期货**：**铜（CU）、铝（AL）**（电缆、换热器）；**没有锂**（液态空气储能不用锂，这是优势）
- **概念板块**：储能、新型电力系统、压缩空气储能、液冷

#### 三、个人生活：身边会变什么

- **能看到/用到的**：青海、甘肃等地出现大型储能电站；**停电会变少**
- **价格与办事**：**峰谷电价差会拉大**（鼓励低谷用电）；家里装光伏 + 储能回本周期缩短
- **工作与收入**：储能运维、电力交易员、并网咨询岗位增加
