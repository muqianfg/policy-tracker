## 术语小词典（本档案用到的人话解释）

| 专业词 | 人话解释 |
| --- | --- |
| **黄河保护治理** | 不是"治理一条河"，是管整个流域 9 个省区的水、沙、生态和**用水权** |
| **16 字治水思路** | 「节水优先、空间均衡、系统治理、两手发力」= 先省着用、把水从多的地方调到缺的地方、上下游一起治、政府和市场都出力 |
| **水法三审稿** | 《水法》（管全国用水的基本法律）修订版第三次提交全国人大常委会审议。中国法律通常"三审"就表决通过 |
| **水价形成机制** | 自来水价、工业水价怎么定、按什么调。草案要求跟"**供水成本、用水户承受能力、节水要求**"相适应 |
| **非常规水** | 不是江河湖泊自然来的水：**雨水蓄集、海水淡化水、矿井（坑）水、微咸水**。草案把它们纳入水资源"统一配置" |
| **再生水** | 污水/废水处理后可再利用的水。草案要求城市绿化等用水**优先用再生水** |
| **国家水网** | 把江河、水库、调水工程连成"水的高速公路网"（六张网之一） |
| **取水许可** | 从江河湖泊或地下取水必须办的许可证。**没有它，工厂开不了工** |
| **水权交易** | 把"用水指标"像配额一样在地区/企业之间买卖 |
| **成本监审** | 政府先核清企业的真实供水成本，再决定能收多少钱。**调价前必须先做** |

## 一、问题（可被证伪）

《水法》修订通过后，2027 年上半年**水利建设投资增速**会不会明显跑赢**基础设施投资整体增速**（差距至少 3 个百分点）？

## 二、我的答案

**会跑赢，且差距至少 3 个百分点。** 逻辑是三层：

1. **"国家水网"入了法**。过去"水网"是规划里的若干重大工程，立法后它是有法律地位的一整套**体系**，地方配水、调水项目的立项依据变硬；
2. **黄河会议把"提升水网工程统筹调配能力"列为第一抓手**。11 月 2 日郑州会议 + 青甘豫鲁四省与国家发改委、水利部发言，说明 **2027 年预算会提前编列**；
3. **水价机制理顺后，水务公司自己也有一部分钱**做管网改造（过去靠财政补贴，现在可以向成本要）。

但必须说清节奏：**2027 年上半年只能看到"投资增速"先动，订单要到 2027 年下半年。**

## 三、验证方式

- **主指标**：① 水利部季度发布会公布的"全国水利建设投资完成额"同比增速；② 国家统计局固定资产投资里"水利管理业投资"增速
- **辅助指标**：各城市水价调整听证会公告数量、再生水/海水淡化项目核准数
- **判据**：
  - 2027 年上半年水利投资增速 > 基建整体增速 +3pt → **判断成立**
  - 两者基本持平或水利更低 → **判断被推翻**（说明水法只是规范性文件，没有增量投资）
  - 水价听证会在一线城市大规模出现 → 说明"价格"这一端比我预期快

### 2026-11-02 · 影响判断

#### 一、创业风口：钱从哪个环节过

| 要素 | 内容 |
| --- | --- |
| **谁在花钱** | **省水利厅 + 市/县水务局**（工程与改造）、**城市供水集团/水务公司**（管网与表计）、**灌区管理单位**（农业水价综合改革）、**工业园区/火电厂**（节水改造与再生水回用） |
| **买什么** | ①**成本监审与调价测算服务**（水价调整前必须先算清成本）；②**智能远传水表/电磁流量计**（分档计量、分区计量 DMA）；③**再生水/矿井水处理成套设备与运维**；④**农业水价计量设施**（井电双控、以电折水）；⑤**水资源论证与取水许可代办** |
| **谁能接** | 工程施工需**水利水电工程施工总承包资质**（特级/一级，个人拿不到）；表计需**计量器具型式批准（CPA）**；成本监审需**会计师事务所/价格评估资质**；**软件与数据分析门槛最低**（水价测算模型、管网漏损分析、水权交易撮合） |
| **单笔规模** | 成本监审与调价咨询 **20~100 万元/城市**；县区节水改造与再生水回用 **100~1,000 万元**；水表改造 **几百元/户**（一个地级市几十万只，总额千万级）；海水淡化 EPC **数亿元** |
| **什么时候** | **2027 年 3–6 月**地方项目集中招标；水价听证一般在**成本监审完成后 3~6 个月** |

**✅ 最现实的可接点**：**"水价测算 + 成本监审"专业服务**。法律把"水价跟成本挂钩"写进去后，**每个想调价的城市都必须先做一次成本核算**，而这类报告要专业机构出。一个省几十个市县 = 几十单。**不构成硬件创业机会**（资质与资金门槛高），服务与软件能接。

- **概念板块**：水利、水务、节水灌溉、海水淡化、管网改造

#### 三、个人生活：身边会变什么

- **能看到/摸到/用到的**：家里**老式水表换成能远传的智能水表**（不用上门抄表）；小区与城市绿化**改用再生水**浇灌；北方部分城市出现**中水管道、再生水加水站**
- **价格与办事**：**水费会分档上涨**（用得多的部分更贵），但**调价前必须开听证会**，能提前看到公告；化工品、纸等耗水产品会小幅变贵
- **工作与收入**：**水利工程、水利设计、水处理运维、计量表计**岗位需求上升；**高耗水工厂**扩产与招人更谨慎
