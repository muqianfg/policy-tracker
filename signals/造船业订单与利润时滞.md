## 术语小词典（本档案用到的人话解释）

| 专业词 | 人话解释 |
| --- | --- |
| **载重吨** | 船能装的重量（货物+燃料+淡水等），是衡量造船量的标准单位 |
| **完工量** | 已造好交付的船，对应"已确认的收入" |
| **新接订单** | 今年新签的合同，对应"未来 2~3 年的活" |
| **手持订单** | 已签合同但还没交付的总量，等于"未来几年的活有多少" |
| **新船价格指数** | 反映新船合同价格水平的指数（克拉克森编制），涨＝船厂议价能力增强 |
| **船板** | 造船专用的厚钢板，是造船最大的原材料成本项 |
| **船级社** | 给船舶做技术认证的机构（DNV、ABS、中国船级社 CCS），进不了它的名录就进不了造船配套 |

## 一、问题（可被证伪）

造船业新接订单 +163.2%、手持订单排满 2~3 年，这个"订单饱和"会不会在 2026Q4—2027 年内转化为船厂毛利率的实质提升（以主要船厂毛利率同比上升 2 个百分点以上衡量）？

## 二、我的答案

会提升，但**幅度小于市场预期，且分化明显**。依据：① 手持订单 39913 万载重吨已锁定未来 2~3 年产能，船厂确实有提价能力（供给瓶颈）；② 但造船合同定价在**签约时**确定，钢材与汇率上涨会侵蚀利润，**2024—2025 年签的低价单还在交付期**；③ 真正受益的是 2025 年后签的高价单，体现在 2027 年后的财报。判断：2026Q4—2027 年船厂毛利率会**小幅改善（1~2 个百分点）**，不会出现"订单爆满→利润暴涨"的线性传导。

## 三、验证方式

- 主要船厂**半年报与年报的毛利率**（同比变化）
- **克拉克森新船价格指数**（是否继续上行）
- **船板价格**（钢材成本占造船成本约 20~30%）
- **判据**：若 2027 年内船厂毛利率同比提升超 3 个百分点，说明我低估了提价能力

## 四、证据时间线（只追加，不改写）

### 2026-10-25 · 立档

- **来源**：《新闻联播》第 6 条 + 工信部 2026 年 1—9 月全国船舶工业统计数据
- **事实**：
  - **造船完工量 5805 万载重吨，同比 +50.7%**
  - **新接订单量 17529 万载重吨，同比 +163.2%**
  - **手持订单量 39913 万载重吨，同比 +64.8%**
  - **全球市场份额：完工 63.6%、新接 81.8%、手持 72.4%**
  - **新接绿色动力船舶订单国际市场份额 74.1%**，比 1—6 月**提高 5.7 个百分点**
- **我的解读**：三个指标对应三件事 —— **完工量是"现在赚的钱"、新接订单是"未来 2~3 年的钱"、手持订单是"产能已被排满"**。最值钱的信息不是增速，而是**手持订单 39913 万载重吨意味着船厂不缺订单、缺产能**，这给了提价能力
- **对判断的影响**：立档

## 七、影响判断（三分法，缺一不可）

### 2026-10-25 · 影响判断

#### 一、创业风口：钱从哪个环节过

| 要素 | 内容 |
| --- | --- |
| **谁在花钱** | 船东（全球航运公司）与船厂 |
| **买什么** | 船用配套设备、LNG/甲醇燃料系统、船舶电气与自动化、船厂扩产的工装与设备 |
| **谁能接** | **必须进船级社（DNV/ABS/CCS）认证与船厂合格供应商名录** —— 这是硬门槛，周期 1~2 年 |
| **单笔规模** | 配套设备单套几百万到几千万 |
| **什么时候** | **现在是产能瓶颈期**，船厂扩产的设备采购窗口在 2027—2028 |

**不构成机会的部分**：整船制造资本与资质双高，个人与小微企业进不去。

#### 二、投资影响：谁被实质影响（**非推荐**）

> ⚠ 本节只列「业务会被实质影响的主体与传导路径」，不构成买入/卖出建议，不预测股价。

| 环节 | 受影响主体（按业务归类） | 为什么受影响 | 财报里要验证什么 |
| --- | --- | --- | --- |
| 中游·整船制造 | 大型船厂 | 手持订单排满 2~3 年，有提价能力 | **毛利率是否上升**（订单≠利润） |
| 上游·船用钢板 | 造船板供应商 | 造船量 +50.7% 直接拉动用钢量 | 船板价格、船板订单占比 |
| 上游·动力系统 | 船用发动机、绿色燃料供应系统厂商 | 绿色船舶份额 74.1% 且升 5.7pp | 绿色动力订单占比 |
| 上游·电气自动化 | 船舶电气与自动化厂商 | 新船电气化程度提高 | 船用电气订单 |
| **被挤压方** | 老船东、旧船资产 | 新船效率高、环保新规下提前退役 | 拆船量、二手船价 |

- **相关大宗/期货**：**热卷（上期所 HC）** —— 船板用钢；**铜** —— 船舶电气与线缆
- **概念板块**：船舶制造 / 绿色船舶

#### 三、个人生活：身边会变什么

- **造船厂周边的招工与配套会变热** —— 焊工、管子工、调试工紧缺
- 如果你在海事、船舶设计、焊接、船用设备销售相关行业，**这两年是少见的景气期**
- 间接影响：**新船效率更高 → 长期海运成本下降 → 部分进口商品可能更便宜**
- 老旧船舶会提前退役拆解，**拆船业（多在东南亚）** 会忙起来

#### 四、跨链传导：还改变了哪个行业的关键参数

> **规则（2026-10-25 新增）**：三分法只覆盖产业链内部。这一节回答「这个变化还改变了哪个不在本产业链里的行业的关键成本」。

| 模式 | 传导链 | 受影响的行业与主体 | 关键参数（可查的数） |
| --- | --- | --- | --- |
| **成本阀门** | 造船订单 → 交船（滞后 2~3 年）→ **集装箱运力增加** → **运价下行** → 跨境电商头程成本下降 | 跨境电商卖家、货代、海外仓、外贸工厂 | **SCFI/CCFI 运价指数** |
| **能力瓶颈** | 船台（造船位）→ 全球运力扩张的上限 → 海运贸易量上限 | 全球航运、大宗贸易 | 全球船台数量与利用率 |
| **门槛变化** | 绿色船舶份额 74.1% → 老旧船被 EU ETS 碳成本挤出 → 只有新船能跑欧洲线 | 船东、欧洲线货主 | 船舶能效指数（EEXI）、碳成本 |

**为什么这条链重要（数字化）**：

| 环节 | 数据 |
| --- | --- |
| 全球集装箱船队 | 约 **3,400 万 TEU** |
| **集装箱船手持订单** | **超 1,400 万 TEU = 现有船队的 42%**（创纪录） |
| 2026 年运力增速 | **+4.6%** |
| **2027 年运力增速（预测）** | **可能加速到 +9%** |
| 2026 年前 7 月全球运量增速 | +5.1% |

**把最后两行放一起看**：**运力增速（4.6%→9%）正在超过运量增速（5.1%）** → 运价有明确下行压力 → **跨境电商头程成本下降**。

**但这条链有三个卡点，不能简化**：

1. **船型不能混算**：1.75 亿载重吨里含 LNG 船、油轮、散货船、集装箱船；集装箱船按 **TEU** 计量，与载重吨不可直接换算。「造船 +163%」推不出「集装箱运力 +163%」
2. **滞后 2~3 年**：今天签的订单 2028—2029 才交船。**现在影响运价的是 2023—2024 年签的单**
3. **运价只占电商成本 10~30%**（头程），运价跌 20~30% → 总成本降 **2~9%**。**除非像 2021 年那样极端，海运不是电商主变量**

**关联信号的影响方向**：

| 关联信号 | 影响 | 说明 |
| --- | --- | --- |
| T-20261025-03（集装箱运力→运价） | **加强** | 本条是它的上游，造船数据是运价的 2~3 年先行指标 |
| T-20261011-01（物流景气） | **弱相关** | 国内物流为主，海运影响小 |
| T-20261010-02（消费结构） | **弱相关** | 通过进口商品价格间接影响 |
