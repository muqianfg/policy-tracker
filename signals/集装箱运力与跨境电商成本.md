## 术语小词典（本档案用到的人话解释）

| 专业词 | 人话解释 |
| --- | --- |
| **TEU** | 20 英尺标准集装箱为一个单位，用来衡量集装箱船能装多少箱子 |
| **手持订单** | 已签合同但还没交船的量，等于"未来几年会新增多少运力" |
| **SCFI** | 上海出口集装箱运价指数，每周五发布，是运价的权威高频指标 |
| **CCFI** | 中国出口集装箱运价指数，覆盖航线更全 |
| **头程** | 货物从国内工厂或仓库运到海外仓或买家手上的第一段运输（多为海运） |
| **EU ETS** | 欧盟碳排放交易体系，2024 年起把航运纳入，排碳要买配额 |
| **EEXI** | 船舶能效指数，超标的老船要么改造要么淘汰 |
| **红海绕行** | 因红海局势，部分船绕道好望角，航程变长相当于"吃掉运力" |

## 一、问题（可被证伪）

集装箱船手持订单已超 1,400 万 TEU（相当于现有船队的 42%），2027 年运力增速可能加速到 9%，会不会在 2027—2028 年内导致集装箱运价（SCFI）中枢明显下移（以年均值同比下降 20% 以上衡量），从而让跨境电商头程物流成本实质下降？

## 二、我的答案

会下降，但**幅度与时间都不确定，且有三个反向力**。依据：① 供给端确定性很高（手持订单占船队 42%，2027 年运力增速可能 9%）；② 需求端只有 +5.1%（2026 前 7 月），**供给增速已超过需求**；③ 但三个反向力会抵消一部分：**红海绕行吃运力**、**EU ETS 碳成本**、**老船拆解**。判断：SCFI 中枢会在 2027—2028 年**下移 20~35%**，但不会回到 2019 年的低位；对跨境电商总成本的影响约 **2~9%**（因为头程只占 10~30%）。

## 三、验证方式

- **SCFI 与 CCFI 周度指数**（每周五发布，最直接）
- 全球集装箱船**运力交付量**（月度，克拉斯克/Alphaliner）
- 红海与苏伊士运河通航状态（绕行取消会突然释放运力）
- 老船拆解量（拆得多会抵消新增运力）
- **判据**：若 SCFI 年均值连续 2 年同比上涨，说明我误判了供给压力

## 四、证据时间线（只追加，不改写）

### 2026-10-25 · 立档

- **来源**：BIMCO（波罗的海国际航运公会）首席航运分析师 Niels Rasmussen 公开表述（经航运媒体转引）+ 今日《新闻联播》造船业数据
- **事实**：
  - 全球集装箱船队约 **3,400 万 TEU**；**手持订单超 1,400 万 TEU，相当于现有船队的 42%**（创纪录）
  - **2026 年运力增速约 +4.6%**；**2027 年可能加速到 +9%**
  - 2026 年前 7 个月，全球集装箱运量同比增长 **+5.1%**
  - 反向力：红海绕行与苏伊士运河通航状态是最大变量，BIMCO 给出"海峡关闭/重开"两种情景
- **上游印证**（今日第 6 条新闻）：中国造船业 1—9 月新接订单 **17529 万载重吨（+163.2%）**、手持订单 **39913 万载重吨（+64.8%）**、绿色动力船舶份额 **74.1%** —— 这些正是未来 2~3 年运力大增的来源
- **我的解读**：**这条信号的价值不在"运价会跌"，而在"它有公开高频数据"**（SCFI 每周五发布）。多数政策信号要等 3~6 个月才有数据，运价每周都有 —— 它是少数能提前看到拐点的变量
- **对判断的影响**：立档

## 七、影响判断（三分法，缺一不可）

### 2026-10-25 · 影响判断

#### 一、创业风口：钱从哪个环节过

| 要素 | 内容 |
| --- | --- |
| **谁在花钱** | 跨境电商卖家（付头程运费）、外贸工厂（FOB/CIF 条款不同，谁付运费不同） |
| **买什么** | 海运舱位、货代服务、海外仓仓储 |
| **谁能接** | 与船公司有长约的货代；有自有海外仓的物流商 |
| **单笔规模** | 一个 40 尺高柜（FEU）的运价视航线而定、差异极大，**必须查 SCFI 才能给具体数字** |
| **什么时候** | 运价下行时，**签长约的时点决定成本**；年度合约通常在每年 Q1 谈 |

**真正可做的生意（不是"运价跌了赚差价"）**：

- **帮中小卖家锁运价**：下行周期里卖家最怕"现在跌、下月涨回来"。做长约撮合与运价风险管理服务有空间
- **运费现金流管理**：运价波动大，卖家的运费占比也随之波动，这是财务管理服务的机会

#### 二、投资影响：谁被实质影响（**非推荐**）

> ⚠ 本节只列「业务会被实质影响的主体与传导路径」，不构成买入/卖出建议，不预测股价。

| 环节 | 受影响主体（按业务归类） | 为什么受影响 | 财报里要验证什么 |
| --- | --- | --- | --- |
| **被挤压方** | 集装箱班轮公司 | 运力过剩 → 运价下行 → 单箱收入下降 | **单箱收入、装载率** |
| 受益方 | 跨境电商卖家、外贸工厂 | 头程成本下降 → 毛利改善 | 运费占营业成本比重 |
| 受益方 | 货代与物流服务商 | 运价波动带来撮合需求 | 代理货量、单箱毛利 |
| 中性偏空 | 造船厂（长期） | 运力过剩 → 未来订单下滑 | 新接订单量 |

- **相关大宗/期货**：无直接期货品种（运价指数期货国内无）；**间接看原油（燃料成本）**
- **概念板块**：航运（偏空）、跨境电商（偏多）、海外仓

#### 三、个人生活：身边会变什么

- **海淘与跨境购物的到货时间可能变快、运费变便宜**
- **进口商品价格有下行压力**（运费是进口成本的一部分）
- 在跨境行业工作的人会发现，**运费谈判从卖方市场变成买方市场** —— 货代开始主动找你
- 出口企业的**报价单更有竞争力**（CIF 条款下运费自己承担，运价跌等于降价空间）
