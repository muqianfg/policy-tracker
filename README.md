# 政策跟踪 · 新闻联播简报与可验证预测（公开仓）

这个仓库是每日《新闻联播》**政策分析 + 可验证预测跟踪**系统的公开部分。

> 每天读《新闻联播》→ 把政策术语翻译成人话 → 推演行业与个人影响 → **写下一个可被证伪的判断** → 之后每天回来对账。对了、错了、还是没有下文，全部留痕。

## 内容在哪

| 目录 | 内容 |
| --- | --- |
| [`新闻自动化/日报/`](新闻自动化/日报/) | 每日简报（三件事 + 行业影响 + 今日答案 + 视频候选） |
| [`新闻自动化/信号/`](新闻自动化/信号/) | 每条跟踪中的判断的完整档案（证据时间线、个人影响与行动项） |
